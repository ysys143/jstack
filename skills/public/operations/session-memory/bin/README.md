# cc-session-sync

Claude Code 세션 JSONL 파일을 마크다운으로 변환하는 Rust 바이너리 소스입니다.

**원본 저장소**: https://github.com/ysys143/cc-session-sync

> 이 파일들은 원본 저장소에서 복사되었습니다.
> 최신 버전은 원본 저장소를 참조하세요.

## 빌드

```bash
cd bin
cargo build --release
# 바이너리: bin/target/release/sync
```

## 의존성

- Rust 1.70+
- `cargo` (https://rustup.rs)
