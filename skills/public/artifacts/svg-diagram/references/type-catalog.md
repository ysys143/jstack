# Type catalog from Diagram Design v2.6.22

Choose the reader's question, then open the linked reference. Paths resolve inside
an immutable upstream snapshot. Apply `upstream-integration.md` before its policy,
density, branding, or export guidance; use jstack's context and output defaults.

Quantitative charts in this catalog remain owned by dataviz. Their references are
available as design material, not as proof that jstack's connector checker validates
numerical accuracy. Never claim 40-type automated layout or visual acceptance.
