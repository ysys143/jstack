# Bloat-only edit

Load this reference only when the user explicitly asks to remove bloat from a
selected artifact. This is a bounded editing operation, not a sixth genre mode.
An ordinary Humanize request continues through its selected genre pipeline.

## Inventory before editing

Read the whole selected artifact. Record its load-bearing claims and rules:
facts, numbers, names, identifiers, quotations, requirements, modality,
negation, conditions, exceptions, uncertainty, and the evidence or caveats on
which each conclusion depends. Record its purpose, intended audience, voice,
genre, and structural relationships. Do not replace this inventory with a
word-count target or infer permission to change a factual claim.

## Compress prose, preserve the contract

Remove repeated wording, empty lead-ins, and needless re-explanation where the
inventory and intended voice survive. Keep detail that a reader needs to
understand or verify a claim. Do not remove a rule, qualification, example with
independent information, or logical dependency merely to shorten the text.
Do not strengthen a claim by dropping uncertainty, conditions, or exceptions.
If the selected artifact is already concise, leave it unchanged.

Handle cross-artifact duplication as a separate source-of-truth task; handle
stale conceptual residue as a separate clean-rewrite task. Report those
findings without editing another artifact unless the user authorized that
scope. A review-only request returns findings without rewriting.

## Check and deliver

Compare the candidate line by line with the inventory. Restore every lost or
altered claim, rule, caveat, voice constraint, and important relationship.
Recheck the full artifact for unsupported implications. A lower word count
does not prove improvement. Return the requested artifact in its requested
format. When commentary is allowed and useful, briefly identify removed
repetition and any out-of-scope residue. Honor body-only output requests.
