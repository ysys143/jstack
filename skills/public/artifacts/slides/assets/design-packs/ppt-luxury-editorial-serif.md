# 럭셔리 에디토리얼 세리프 — ppt 디자인 팩

## 이 스타일의 정체성
패션 하우스풍 절제된 럭셔리. 넓은 여백의 오프화이트 지면에 가는 하이콘트라스트 디드로(Didone) 세리프, 넉넉한 자간의 소문자 캡션. 무채색 팔레트에 절제된 골드 한 점. 정적이고 우아하며 비어 있다 — 한눈에 "고급 매거진·럭셔리 브랜드 룩북"으로 식별된다.

## 색
- 배경: `#FAF8F3`(오프화이트 / 샹파뉴 화이트). 보조 표면 없음 — 단일 지면.
- 텍스트: `#1A1814`(잉크 차콜). 잉크 블랙(#000) 대신 살짝 따뜻한 차콜.
- 강조색 1개만: `#A8884E`(절제된 골드) — 가는 룰 라인·키워드·페이지 번호에만, 면적 극소.
- 보조 텍스트: `#8C887E`(웜 그레이).
- 그라디언트·면 채움 컬러 블록 금지. 색은 무채 + 골드 한 점.

## 타이포그래피
- 헤드라인: `Playfair Display` 또는 `Bodoni Moda` (대체: `Noto Serif KR`, serif) — 하이콘트라스트 디드로. 표지 52pt / Regular(굵게 쓰지 않음 — 가늘게), 본문 제목 34pt.
- 본문: `Noto Serif KR` Light 또는 Regular 22pt, 행간 1.6. 슬라이드당 6줄 이하.
- 캡션/라벨: `Inter` 또는 `Pretendard` 13pt, 대문자, 자간 0.22em — 넉넉히 벌린 트래킹이 핵심.
- 헤드라인은 소문자 또는 문장형, 절대 굵게(Bold) 쓰지 않음 — 가는 우아함.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 여백 광활 — 좌우 각 1.5in, 상하 각 1.2in.
- 콘텐츠는 캔버스 중앙 정렬을 기본으로, 단일 컬럼. 콘텐츠 폭 캔버스의 55% 이하.
- 슬라이드 대부분이 비어 있어야 한다 — 텍스트는 화면 면적의 40% 이하 점유.
- 슬라이드 번호 우하단 13pt 골드 캡스, 자간 넓게.

## 형태 / 질감
- 룰 라인: 0.5pt 골드 또는 차콜 가는 수평선 — 헤드라인 위/아래 액센트.
- 보더 박스·둥근 모서리 카드·그림자 전부 금지. 면을 가두지 않는다.
- 모서리 반경 0(박스를 거의 안 쓰므로 무의미).
- 이미지: 사용 시 보더 없는 풀톤 고급 사진, 풀블리드 또는 콘텐츠 폭 이내. 채도 살짝 낮춤.
- 배경: 미세 종이 질감 가능(불투명도 4% 이하), 거의 보이지 않게.

## 전환 (PPT)
- 전환은 Fade, 0.6s — 느리고 우아하게. Push·Bounce·Morph 금지.

## 하지 말 것
- 헤드라인을 굵게(Bold) 쓰지 말 것 — 가는 디드로 세리프가 정체성이다.
- 골드 외 색 추가 금지. 그라디언트·컬러 면 채움 금지.
- 박스·카드·보더·그림자 금지.
- 산세리프 헤드라인 금지(산세리프는 캡션 활자에만).
- 콘텐츠로 슬라이드를 채우지 말 것 — 광활한 여백이 정체성이다.
- 이모지·아이콘·일러스트·클립아트 금지.
- 자간 좁은 캡션 금지 — 캡션 트래킹 0.22em 유지.
- **차트 금지사항(아마추어 회귀 차단):** 3D·입체·원근 차트 금지. 그림자(하드·소프트 모두) 금지. 격자선 금지 — 헤어라인 라인 차트엔 격자선 자체가 이질적이다. 범례 박스 금지 — 직접 레이블링만. 골드 외 색·무지개 다색 라인 금지. 굵은 라인(2pt 초과) 금지 — 헤어라인 0.75pt만. 면적 채움(area fill) 금지 — 면을 칠하지 않는다. 막대 차트·도넛·파이 금지 — 럭셔리 팩은 라인 차트 또는 거대 세리프 수치만. 잘린 y축 금지. 데이터 영역 테두리 박스 금지. div·표 셀 막대 금지 — SVG 정밀 렌더.

## 차트·데이터 시각화
럭셔리 차트 = 헤어라인 라인 차트 + 광활한 여백 + 골드 단색 강조 + 세리프 캡션. 차트는 데이터를 보여주는 도구가 아니라 지면의 우아한 한 요소로 다룬다 — 거의 보이지 않을 만큼 가늘게, 면적의 40% 이내에 작게 앉힌다.
- **렌더링:** SVG로 정밀하게 그린다. 꺾은선은 직선 세그먼트(부드러운 곡선 보간 금지 — 절제). 꼭짓점은 마커 없음 또는 지름 4pt 골드 속찬 원만. 데이터 좌표는 정확히, 안티앨리어싱된 깔끔한 헤어라인.
- **축·격자:** 격자선 완전 제거. x축 기준선만 0.5pt 차콜 `#1A1814` 헤어라인, y축선 제거. 눈금 라벨은 0과 최댓값 2개만, `Inter` 13pt 대문자 자간 0.22em 웜 그레이 `#8C887E`. 축 기준선은 반드시 값 0에서 시작 — 잘린 y축 금지.
- **데이터 색:** `tokens.json`의 `color.chart`. 보조 라인은 전부 차콜 `#1A1814` 0.75pt 헤어라인. 강조하려는 라인 1개만 골드 `#A8884E` 0.75pt — 색 자체가 강조이므로 굵기는 동일하게 둔다. 무지개 다색 라인 금지.
- **값 레이블:** 라인의 시작·끝 꼭짓점 또는 최고점에만 직접 표기(모든 점에 붙이지 않음 — 절제). `Playfair Display` Regular 20pt 차콜로 수치, 항목명은 `Inter` 13pt 대문자 자간 0.22em 웜 그레이. 일관된 자릿수·단위.
- **직접 레이블링:** 범례 박스 금지. 계열명은 라인 끝에 13pt 대문자 캡션으로 직접 붙인다.
- **차트 타입:** 추세=0.75pt 헤어라인 꺾은선(차콜 + 강조 1골드)만이 기본. 단일 핵심 메트릭은 차트 대신 `Playfair Display` 가는 100pt 거대 세리프 수치 + 그 아래 0.5pt 골드 룰 라인 + 13pt 대문자 캡션으로 표현 — 팩 정체성과 일치. 막대·도넛·파이는 이 팩에서 쓰지 않는다.
- **여백:** 차트 자체가 슬라이드 면적의 40% 이내. 좌우·상하 광활한 여백을 그대로 둔다.

## 다이어그램·컴포넌트
럭셔리 다이어그램 = 0.5pt 골드 헤어라인 + 넉넉한 여백 + 가는 세리프 번호 + 대문자 넓은 자간 캡션. 면을 채우지도 가두지도 않는다 — 노드는 박스가 아니라 헤어라인 룰과 활자의 정렬로 암시한다. 한 언어를 공유한다 — 모든 선은 0.5pt 골드 또는 차콜 헤어라인, 번호는 가는 `Playfair Display` 세리프 숫자, 라벨은 `Inter` 13pt 대문자 자간 0.22em, 강조는 골드 한 점. 박스·그림자·둥근 카드·아이콘 절대 금지. 전부 SVG 정밀 렌더, div 블록 금지.
- **공통 다이어그램 언어:** 노드 = 박스 없음. 단계는 0.5pt 헤어라인 룰 + 활자 블록으로 표현. 커넥터 = 0.5pt 차콜 `#1A1814` 헤어라인 직선(곡선 금지, 화살촉 없음 또는 변 0.1in 가는 골드 선 화살촉). 번호 = `Playfair Display` Regular 가는 36pt 세리프 숫자(원형 배지 없음, 숫자만), 그 아래 0.3in 골드 헤어라인. 강조는 골드 `#A8884E` 단색 — 면적 극소.
- **프로세스 플로우:** 4~5단계, 박스 없는 수평 배열. 각 단계 = 가는 36pt 세리프 번호 + 그 아래 0.5pt 골드 룰 라인(폭 0.6in) + 22pt 세리프 헤드라인 + 13pt 대문자 자간 0.22em 캡션. 단계 사이는 0.5pt 차콜 헤어라인 한 줄로만 연결(화살촉 생략 가능). 현재/핵심 단계 번호 1개만 골드. 단계 폭 균등, 사이 광활한 여백.
- **타임라인:** 수평 축 = 0.5pt 차콜 `#1A1814` 헤어라인 직선, 캔버스 콘텐츠 폭(55%) 이내. 마일스톤 마커 = 축 위 지름 4pt 골드 속찬 원(차트 vertex 마커와 동일 어휘). 마커 위에 13pt 대문자 자간 0.22em 날짜, 그 위 22pt 세리프 헤드라인. 현재 시점만 지름 6pt 골드 원 + 그 아래 0.5pt 골드 짧은 수직 헤어라인. 마커 간격 날짜 비례.
- **비교 레이아웃:** 2열 대조만(3열 금지 — 절제), 콘텐츠 폭 55%를 좌우로 나눠 배치. 열 구분은 가운데 0.5pt 차콜 수직 헤어라인 1줄. 각 열 상단 34pt 가는 세리프 헤드라인 + 그 아래 0.5pt 골드 룰, 항목은 22pt 세리프(불릿 없음, 줄바꿈으로 구분). 우세 열은 헤드라인만 골드. vs 표기는 가운데 헤어라인 위 가는 세리프 소문자 "versus".
- **매트릭스 2×2:** 사분면 = 0.5pt 차콜 헤어라인 십자선만(셀 채움·보더 박스 절대 없음), 한 변 3.6in, 콘텐츠 영역 중앙. 축 라벨 = 사분면 바깥 끝에 13pt 대문자 자간 0.22em 웜 그레이 `#8C887E`. 데이터 포인트 = 지름 4pt 골드 속찬 원 + 옆 22pt 세리프 라벨, 핵심 포인트 1개만 지름 6pt 골드 원. 사분면 안은 비워 둔다.
- **계층/퍼널:** 박스 없는 수직 적층 — 각 레벨은 가로 0.5pt 차콜 헤어라인 + 그 위 22pt 세리프 헤드라인 + 13pt 대문자 캡션. 레벨 폭을 위→아래(계층)·아래→위(퍼널)로 헤어라인 길이로만 단계 축소(폭 차이 0.8in씩), 채움 면 없음. 레벨 간격 0.5in 넉넉히. 정점/핵심 레벨 헤어라인 1개만 골드.
- **KPI·스탯 카드:** 카드는 박스 없음 — 거대 수치 `Playfair Display` 가는 100pt 세리프 숫자(차콜, 핵심 1개만 골드) + 그 아래 0.5pt 골드 룰 라인(폭 0.8in) + 13pt 대문자 자간 0.22em 웜 그레이 라벨. 증감은 작은 가는 골드 또는 차콜 세리프 +/- 기호 + 13pt 수치(▲▼ 같은 채운 도형 금지). 메트릭 2~3개는 콘텐츠 폭 안에 균등, 사이 광활한 여백.

## 적용 예
- 표지: 오프화이트 지면, 중앙 상단에 52pt 가는 디드로 제목, 그 아래 0.5pt 골드 룰 라인, 룰 아래 13pt 넓은 자간 골드 캡스 부제. 나머지 70%는 여백.
- 본문: 중앙 정렬 34pt 가는 제목, 한 줄 띄우고 22pt 본문 5줄(행간 1.6). 좌우 광활한 여백.
- 다이어그램(프로세스): SVG 박스 없는 4단계 배열. 각 단계 가는 36pt 세리프 번호 + 폭 0.6in 골드 헤어라인 룰 + 22pt 세리프 헤드라인 + 13pt 대문자 캡션, 단계 사이 0.5pt 차콜 헤어라인 한 줄. 핵심 단계 번호 1개만 골드, 광활한 여백 유지.
- 다이어그램(타임라인): SVG 헤어라인 타임라인. 0.5pt 차콜 헤어라인 축 + 지름 4pt 골드 속찬 원 마커, 13pt 대문자 자간 0.22em 날짜. 현재 시점만 지름 6pt 골드 원 + 골드 수직 헤어라인. 콘텐츠 폭 55% 이내.
- 차트: SVG 헤어라인 라인 차트. 보조 라인 전부 차콜 `#1A1814` 0.75pt, 핵심 라인 1개만 골드 `#A8884E` 0.75pt(같은 굵기 — 색이 강조). 격자선 완전 제거, x축만 0.5pt 차콜 헤어라인, 기준선 값 0. 값 레이블은 라인 끝·최고점에만 `Playfair Display` 20pt로, 항목명은 13pt 대문자 자간 0.22em 웜 그레이 직접 표기. 차트는 면적 40% 이내, 광활한 여백 유지. 단일 메트릭이면 차트 대신 100pt 가는 세리프 거대 수치.
