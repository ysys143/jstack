# 모노크롬 리스크 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 모노크롬 리스크 — 순수 흑백/회색 단계만, 색 전무. 굵은 산세리프 경고 헤드라인, 두꺼운 룰 라인 구획, 의도적으로 엄숙한 톤.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 어떤 슬라이드에도 색이 한 점도 없음 — 흑·백·회색 5단계만, (2) 거대하고 굵은 산세리프 헤드라인이 경고문처럼 단호하게, (3) 2~4px 두꺼운 검정 룰 라인이 영역을 가른다. 위험 보고서·감사 보고서의 엄숙함.

## 색
- 배경 `#FFFFFF`
- 텍스트·룰 라인 `#0A0A0A`
- 회색 5단계만: `#0A0A0A`(잉크) / `#3D3D3D`(다크) / `#767676`(미드) / `#B0B0B0`(라이트) / `#E6E6E6`(페일)
- 강조 표면(경고 블록): `#0A0A0A` 채움 + 흰 텍스트, 반전으로 강조 — 색이 아니라 명도 반전으로만 강조.
- **컬러 절대 금지.** 차트·아이콘·강조 전부 회색 단계 + 흑백 반전으로만.

## 타이포그래피
- 디스플레이 폰트: `Helvetica Neue` Bold (대체 `Arial Black`, `Pretendard`). 한글은 `Pretendard` Bold.
- 본문 폰트: `Helvetica Neue` (대체 `Arial`, `Pretendard`).
- 헤드라인: 44pt / Bold(700) / 자간 -2% / 행간 1.05 / 대문자
- 서브헤드: 22pt / Bold / 대문자
- 본문: 17pt / Regular / 행간 1.4 / 슬라이드당 최대 6줄
- 라벨/넘버: 12pt / Bold / 자간 +10% / 대문자
- 캡션: 10pt / Regular / 색 `#767676`

## 레이아웃 / 그리드
- **엄격 그리드.** 좌우 여백 0.7in, 상하 0.55in. 콘텐츠를 두꺼운 룰 라인으로 수평·수직 구획.
- 헤드라인 상단 고정, 그 아래 3px `#0A0A0A` 룰 라인.
- 본문은 좌측 정렬 블록. 경고·핵심 메시지는 검정 채움 블록 안 흰 글자로 반전.
- 슬라이드 번호는 하단 외측, 12pt Bold.

## 형태 / 질감
- 모서리 반경 0px (직각). 그림자 금지.
- 구획은 룰 라인으로만 — 2px(가는 구분) / 4px(섹션 구분). 박스 보더도 직각 흑색.
- 아이콘은 2.5px 스트로크 라인 아이콘, 검정 단색. 경고 표시는 삼각형 픽토그램.

## 차트 / 데이터 시각화 (무채색 — 명도 인코딩 + 룰 라인)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 이 팩의 차트 정체성은 "색 한 점 없이 회색 명도만으로 데이터를 인코딩하고, 룰 라인으로 엄격히 구획"이다 — 감사·위험 보고서의 차트.
- **데이터 색(명도 인코딩 고정):** 컬러 절대 금지. 강조할 막대 1개만 잉크 블랙 `#0A0A0A`, 나머지는 라이트 그레이 `#B0B0B0` — 명도 대비로 핵심을 떠올린다(컨설팅식 강조의 무채색 버전). 계열이 2개 이상이면 `#0A0A0A`·`#767676` 두 단계만 쓰거나, 한쪽을 사선 해칭 패턴(`#0A0A0A` 1px 선, 5px 간격, 45°)으로 구분. 절대 회색을 3단계 이상 막대에 동시에 쓰지 않는다(혼탁해짐).
- **데이터 잉크 최소화:** 차트 테두리 박스 제거, 플롯 배경 채움 제거, 범례 박스 제거 — 계열명은 막대·선 끝에 12pt Bold 대문자 라벨로 직접. 격자선은 y축 주요 눈금에 `#E6E6E6` 0.5pt 헤어라인 **1개만**(최댓값 위치).
- **축:** x축 베이스라인만 `#0A0A0A` 1pt 실선(이 팩은 룰 라인 미감이므로 헤어라인이 아니라 또렷한 1pt). y축선 생략. **막대 기준선 반드시 0에서 시작**(잘린 y축 금지 — 위험 데이터 왜곡은 치명적).
- **값 레이블:** 막대 끝/꼭짓점에 값을 직접 표기, `Helvetica Neue` **14pt Bold**, 색 `#0A0A0A`, 자릿수·단위 일관, 탭형(tabular) 정렬. 카테고리명은 막대 아래 12pt Bold 대문자 `#3D3D3D`. 축에서 눈으로 읽게 하지 않는다.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 반경 0px(직각 — 팩 전체가 직각). 모든 막대 베이스라인·정렬 픽셀 정확. 라인 차트는 2pt 실선 `#0A0A0A`, 보조 계열은 2pt 점선(dash 6 gap 4) `#767676`, 마커는 끝점·강조점만 작은 정사각.
- **차트 타입 매칭:** 비교=세로/가로 막대, 추세=라인. 도넛·파이 지양(쓸 경우 조각 2개·무채색 명도 2단계, 중앙에 핵심 수치 28pt Bold). 무지개·다계열 난색 절대 금지.
- **출처:** 차트 하단 좌측 10pt `#767676` 출처 캡션 + 단위. 차트와 본문 사이 2px `#0A0A0A` 룰 라인으로 구획.

## 다이어그램·컴포넌트 (무채색 — 룰 라인 + 명도 인코딩 키트)
색·명도만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며(div 블록 금지), **하나의 다이어그램 언어**를 공유한다 — 모든 노드는 직각 0px, 보더는 2px 또는 4px `#0A0A0A` 룰 라인, 커넥터는 2pt 직각 실선 + 날카로운 삼각 화살촉 `#0A0A0A`(곡선 금지), 단계/레벨 번호는 0.4in 정사각(검정 채움·흰 12pt Bold 대문자 라벨), 강조는 검정 채움 반전(흰 글자)으로만 — 색 한 점 없음.
- **프로세스 플로우:** 직각 사각 노드(높이 0.85in, 흰 채움 + 2px `#0A0A0A` 보더, 0px 모서리), 노드 좌상단에 0.4in 검정 정사각 번호 칩(흰 숫자), 노드 사이 2pt `#0A0A0A` 직각 커넥터 + 날카로운 삼각 화살촉. 활성/위험 단계 노드만 검정 `#0A0A0A` 채움 + 흰 텍스트 반전. 가로 4~5단계.
- **타임라인:** 수평 2px `#0A0A0A` 룰 라인 축, 마일스톤은 0.16in 정사각 마커(`#0A0A0A`), 현재 시점은 검정 채움 정사각 + 위에 12pt Bold 대문자 라벨. 날짜는 축 아래 12pt Bold 대문자 `#3D3D3D`, 이벤트명 축 위 17pt. 위험·지연 마일스톤은 삼각형 픽토그램으로 표시(색 아닌 형태로 경고).
- **비교 레이아웃:** 2~3열, 각 열 사이 4px `#0A0A0A` 세로 룰 라인으로 구획, 열 헤더는 22pt Bold 대문자 + 아래 3px 룰. 우세 열은 검정 채움 반전 / 열세 열은 흰 채움. 항목 행 사이 2px 룰. 우열은 체크/엑스 삼각 픽토그램(색 없이 형태로).
- **매트릭스 2×2:** 십자 축을 2px `#0A0A0A` 룰 라인 2개, 4축 끝에 12pt Bold 대문자 축 라벨, 사분면 채움 없음. 데이터 포인트는 0.28in 정사각(`#0A0A0A` 채움), 핵심 사분면(우상)은 사분면 전체를 `#E6E6E6` 페일 채움. 사분면 제목은 각 칸 좌상단 12pt Bold 대문자.
- **계층/퍼널:** 계층은 직각 사각 노드 + 2pt `#0A0A0A` 수직 직각 커넥터, 레벨 라벨 좌측에 0.4in 검정 정사각 번호 칩. 퍼널은 위→아래 폭 좁아지는 4단 직각 사다리꼴, 각 단 회색 명도(페일→잉크, 최대 2~3단계만 — 혼탁 방지) 또는 검정 채움/사선 해칭 교대, 단 우측에 단계명 14pt Bold + 수치.
- **KPI·스탯 카드:** 직각 박스(2px `#0A0A0A` 보더, 0px 모서리), 강조 카드는 검정 채움 + 흰 텍스트 반전. 거대 수치 36pt Bold `#0A0A0A`(반전 카드는 흰색), 위에 12pt Bold 대문자 라벨, 아래 증감은 ▲▼ 삼각 글리프 + 명도 단계(색 아닌 형태·명도로). 카드 사이 2px 룰 라인.
- **목차/섹션 디바이더:** 목차는 0.4in 검정 정사각 번호 칩 + 22pt Bold 대문자 항목명 세로 배열, 항목 사이 2px 룰. 디바이더는 흰 배경 + 거대 장 번호 120pt Bold `#E6E6E6` 워터마크 + 44pt 대문자 장 제목 + 4px 룰. 인용 슬라이드는 검정 채움 블록 안 흰 글자 풀쿼트 + 좌측 거대 따옴표 글리프.

## 전환 (PPT)
즉시 컷만. 페이드·모핑 금지 — 단호함이 톤.

## 하지 말 것
- 어떤 색이라도 사용 — 흑·백·회색 5단계 외 절대 금지(빨강 경고색조차 금지, 강조는 흑백 반전·명도 대비로). 차트 막대·선·도넛도 회색 명도만.
- 둥근 모서리, 그림자, 그라디언트.
- 가는 헤드라인 — 헤드라인은 반드시 Bold 이상, 단호하게.
- 부드럽고 친근한 톤, 이모지, 클립아트, 일러스트.
- 본문을 6줄 넘게 채우기.
- 룰 라인 없이 여백만으로 구획 — 구획은 두꺼운 룰로 명시.
- **아마추어 차트 회귀 금지:** 3D·입체 막대·입체 도넛, 막대/조각 그림자·베벨, 색 사용(무채색 명도만), 막대 그라디언트 채움, 회색 3단계 이상 동시 사용(혼탁), 격자선 과다(1개만)·범례 박스, 차트 테두리 박스·플롯 배경 채움, 잘린 y축(0 기준선 필수), 둥근 막대(직각 0px), 값 레이블 누락·출처 누락.

## 적용 예
- **표지:** 흰 배경, 상단 12pt 라벨, 44pt 대문자 경고 헤드라인 2줄, 그 아래 3px 룰 라인. 하단에 검정 채움 블록 안 흰 글자로 부제.
- **본문 슬라이드:** 헤드라인 + 3px 룰, 그 아래 본문을 2px 룰로 3개 블록 구획. 핵심 한 블록은 검정 반전.
- **차트 슬라이드:** SVG 무채색 막대 차트 — 강조 1막대만 잉크 블랙 `#0A0A0A`·나머지 라이트 그레이 `#B0B0B0`, 막대 폭:간격 3:2·직각 0px, x축 1pt 검정 베이스라인·격자선 1개·0 기준선, 막대 끝 14pt Bold 값 레이블·12pt 대문자 카테고리명. 차트와 우측 해석 텍스트(3줄) 사이 2px 룰 라인. 하단 10pt 출처·단위.
- **프로세스 슬라이드:** 헤드라인 + 3px 룰, 가로 4단계 직각 사각 노드(각 좌상단 0.4in 검정 정사각 번호 칩), 노드 사이 2pt 직각 커넥터 + 삼각 화살촉. 위험 단계 노드만 검정 채움 반전.
- **매트릭스 슬라이드:** 헤드라인 + 3px 룰, 2px `#0A0A0A` 룰 라인 십자 축, 4축 12pt Bold 대문자 라벨, 데이터 항목은 0.28in 검정 정사각. 핵심 사분면(우상)은 `#E6E6E6` 페일 채움.
- **KPI 슬라이드:** 직각 KPI 박스 3개를 2px 룰로 구획 — 각 36pt Bold 수치 + 12pt 대문자 라벨 + ▲▼ 삼각 증감 글리프, 핵심 카드 1개는 검정 채움 반전.
