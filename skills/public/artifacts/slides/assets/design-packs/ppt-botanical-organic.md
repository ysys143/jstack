# 보태니컬 오가닉 — ppt 디자인 팩

## 이 스타일의 정체성
어스 톤 자연주의. 베이지·테라코타·모스그린의 따뜻한 흙빛 팔레트 위에 손그림 식물 일러스트(잎·줄기·가지)와 유기적 곡선 형태가 흐른다. 종이·린넨 질감 배경, 부드러운 세리프 헤드라인, 직선·직각을 피하고 곡선으로만 구획한다 — 한눈에 "따뜻하고 자연스러운 손맛"으로 식별된다.

## 색
- 배경: `#F2EAD9`(린넨 베이지). 보조 표면: `#E5D9C3`(딥 베이지).
- 텍스트: `#3A352C`(웜 다크 브라운). 잉크 블랙 금지 — 갈색 톤으로.
- 어스 강조 3색: `#B5654A`(테라코타), `#7C8B5A`(모스그린), `#C99A5B`(머스터드 오커). 한 슬라이드에 1~2색만.
- 식물 일러스트 색: 모스그린 + 테라코타 단색 라인 또는 플랫 채움.
- 순수 채도 원색·네온·그라디언트(메시) 금지. 모든 색은 채도를 낮춘 흙빛.

## 타이포그래피
- 헤드라인: `Cormorant Garamond` (대체: `Noto Serif KR`, serif). 표지 48pt, 본문 제목 34pt. 굵기 Medium, 자간 0.
- 본문: `Noto Sans KR` Regular (대체: sans-serif). 24pt, 행간 1.5. 슬라이드당 7줄 이하.
- 캡션: `Cormorant Garamond` Italic 18pt — 손글씨 같은 부드러움.
- 헤드라인은 소문자 혹은 문장형, 대문자 강조 금지.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 여백 넉넉히 — 좌우 각 1.0in, 상하 각 0.9in.
- 비대칭 배치: 텍스트 블록을 좌 또는 우 한쪽으로 몰고 반대편에 식물 일러스트·유기 곡선 여백.
- 참조 그리드 8열이되 경계는 곡선 셰이프로 부드럽게 흐트러뜨린다.
- 식물 일러스트는 슬라이드 모서리에서 자라 들어오듯 1~2개 배치, 슬라이드마다 위치 변경.

## 형태 / 질감
- 형태: 유기적 블롭·물결 띠·잎 실루엣. 모서리 반경은 비균일 큰 곡선(원형보다 자유 곡선).
- 보더: 사용 시 1.5pt 테라코타 또는 모스그린 가는 라인. 검정 보더 금지.
- 그림자: 아주 옅은 확산 그림자만 허용(블러 24pt, 불투명도 10%, 색 `#3A352C`). 하드 섀도 금지.
- 배경: 미세한 종이/린넨 그레인 텍스처 오버레이(불투명도 6~10%).
- 이미지: 사용 시 유기 블롭 마스크로 클리핑. 사각 프레임 금지.

## 전환 (PPT)
- 전환은 Fade, 0.5s. 식물 요소는 Wipe(아래에서 위, 0.6s)로 "자라나는" 느낌. 빠른 Push·Bounce 금지.

## 하지 말 것
- 순수 원색·네온·메시 그라디언트 금지. 채도 높은 색 금지.
- 잉크 블랙(#000) 텍스트 금지 — 웜 브라운으로.
- 직각 보더 박스·하드 섀도·둥근 모서리 카드(균일 라운드) 금지.
- 직선만으로 구획하지 말 것 — 곡선·유기 형태가 정체성이다.
- 스톡 아이콘·이모지·기하 도형 장식 금지. 장식은 식물 일러스트·유기 곡선으로만.
- 슬라이드를 가득 채우지 말 것 — 숨 쉬는 여백 유지.
- **차트 금지사항(아마추어 회귀 차단):** 3D·입체 막대·드롭 그림자 금지. 하드 섀도 금지. 격자선 금지. 범례 박스 금지 — 직접 레이블링만. 무지개색·순수 채도 원색 금지 — 어스 톤만. 잘린 y축 금지. 데이터 영역 테두리 박스 금지. div·표 셀 막대 금지 — SVG 정밀 렌더.

## 차트·데이터 시각화
보태니컬 차트 = 어스 톤 단색 + 부드러운 곡선 + 헤어라인. 데이터 잉크는 최소화하되 채움·라인은 흙빛 자연 톤만.
- **렌더링:** SVG로 정밀하게 그린다. 막대는 폭 : 간격 = 3 : 2, 막대 상단 모서리만 부드러운 라운드(반경 6pt) 허용 — 유기적 손맛. 막대 하단 기준선은 값 0에 정확히 정렬. 잘린 y축 금지.
- **축·격자:** 격자선 완전 제거. x축(기준선)만 1pt 모스그린 `#7C8B5A` 솔리드. y축선 제거. 눈금 라벨 최소(0·최댓값).
- **데이터 색:** `tokens.json`의 `color.chart` 어스 3색(`#B5654A`·`#7C8B5A`·`#C99A5B`)만. 단일 계열 막대는 모스그린 `#7C8B5A` 단색 + 강조 막대 1개만 테라코타 `#B5654A`. 다계열은 3색 이내. 명도 단계가 필요하면 모스그린 명/암 2단(`#A4AE86`·`#7C8B5A`).
- **값 레이블:** 막대 위·꼭짓점 옆에 직접 표기. `Cormorant Garamond` 18pt `#3A352C`(웜 브라운), 일관된 자릿수·단위.
- **직접 레이블링:** 범례 박스 금지. 항목명은 막대 아래, 계열명은 면적·라인 끝에 `Cormorant Garamond` Italic 16pt로 직접 붙인다.
- **차트 타입:** 추세=옅은 면적 차트(어스 톤 채움 불투명도 30%) + 1.5pt 윤곽선. 비중=도넛(조각 3개 이하, 어스 3색, 중앙에 핵심 수치 `Cormorant Garamond` 34pt). 비교=라운드드 막대. 파이 4조각+·다중 도넛 금지.
- **장식:** 차트 모서리 한쪽에 모스그린 잎 가지 일러스트 1개를 곁들이되 데이터 영역은 침범하지 않는다.

## 다이어그램·컴포넌트
보태니컬 다이어그램 키트 = 유기 블롭·곡선 노드 + 흙빛 1.5pt 가는 라인 커넥터 + 부드러운 곡선만. 직선·직각·하드 섀도 금지. 노드는 비균일 큰 곡선 블롭, 커넥터는 1.5pt 모스그린 곡선 라인 + 작은 잎형 화살촉. 모든 다이어그램이 이 한 언어를 공유하며 차트와 동일한 어스 톤·곡선·옅은 그림자. 전부 SVG 정밀 렌더, div 블록 금지.
- **공통 다이어그램 언어:** 노드는 유기 블롭 또는 모서리 반경이 비균일한 둥근 형태(원형·직각 금지). 채움은 `color.chart` 어스 3색 또는 명도 단계(`#A4AE86`·`#7C8B5A`), 옅은 확산 그림자만(블러 24pt, 불투명도 10%, `#3A352C`). 커넥터는 1.5pt 모스그린 `#7C8B5A` 곡선(직선 금지) + 잎형 화살촉. 단계 번호 배지는 지름 0.55in 유기 원형, 머스터드 오커 `#C99A5B` 채움 + `Cormorant Garamond` 22pt 웜 브라운 숫자. 강조 노드 1개만 테라코타 `#B5654A`.
- **프로세스 플로우:** 가로 또는 완만한 곡선을 따라 흐르는 4~5단계. 각 노드 유기 블롭 1.8in×1.0in, 어스 톤 채움 + 옅은 확산 그림자. 노드 좌상단에 0.55in 번호 배지. 커넥터는 1.5pt 모스그린 곡선 라인(노드를 곡선으로 잇는다). 노드 라벨 `Noto Sans KR` 18pt. 단계 사이에 작은 잎 일러스트 1개씩 곁들임.
- **타임라인:** 완만하게 굽이치는 1.5pt 모스그린 곡선 축(직선 금지 — 줄기처럼). 마일스톤 마커는 지름 0.4in 유기 원(어스 톤 채움), 축을 따라 잎이 나듯 위아래 교차. 날짜 라벨 `Cormorant Garamond` Italic 16pt 웜 브라운. 현재 시점은 테라코타 `#B5654A` 원 + 작은 새싹 일러스트.
- **비교 레이아웃:** 2~3열. 각 열은 유기 블롭 패널, 딥 베이지 `#E5D9C3` 채움 + 1.5pt 어스 톤 가는 라인 테두리. 열 상단에 34pt 세리프 헤더. 열 사이 구분은 모스그린 잎 가지 일러스트 1개 또는 1.5pt 곡선 디바이더 — 직선 구분선 금지. 가운데에 머스터드 오커 작은 원형 "vs" 라벨.
- **매트릭스 2×2:** 두 축은 1.5pt 모스그린 솔리드 라인이되 끝을 살짝 곡선 처리. 사분면은 어스 3색 + 명도 단계로 옅게 채움(불투명도 20%). 축 라벨 `Cormorant Garamond` Italic 18pt 웜 브라운. 데이터 포인트는 지름 0.45in 유기 블롭(어스 톤 채움 + 옅은 그림자), 라벨은 점 옆 16pt 이탤릭.
- **계층/퍼널:** 위→아래로 폭이 줄어드는 유기 곡선 단(잎맥·꽃잎이 겹친 형태), 3~4단. 각 단 어스 3색 채움 + 옅은 확산 그림자, 단 경계는 곡선. 단 사이 0.15in 간격. 레벨 라벨은 단 안 `Cormorant Garamond` 22pt. 정렬은 중심축 기준이되 좌우 곡선은 비대칭.
- **KPI·스탯 카드:** 유기 블롭 카드 2.7in×2.0in, 딥 베이지 `#E5D9C3` 채움 + 1.5pt 어스 톤 가는 라인 테두리 + 옅은 확산 그림자. 거대 수치는 `Cormorant Garamond` 60pt 웜 브라운, 라벨은 하단 18pt 이탤릭, 증감은 작은 잎 화살표(▲ 대신 위 향한 새싹) + 수치 18pt. 카드는 모서리에 잎 일러스트 1개씩.

## 적용 예
- 표지: 린넨 베이지 배경, 좌측에 48pt 세리프 제목(웜 브라운), 우측 모서리에서 모스그린 잎 가지가 자라 들어옴, 하단 테라코타 이탤릭 캡션.
- 본문: 우측 60%에 텍스트(34pt 제목 + 24pt 본문 6줄), 좌측 40%는 유기 블롭 셰이프 + 식물 일러스트 1개.
- 차트: SVG 도넛 또는 옅은 면적 차트. 채움은 `color.chart` 어스 3색(`#B5654A`·`#7C8B5A`·`#C99A5B`), 단일 계열은 모스그린 + 강조 1개만 테라코타. 막대는 폭:간격 = 3:2, 상단 모서리 6pt 라운드. 격자선·범례 제거, x축만 1pt 모스그린, 기준선 0. 값 레이블 18pt `Cormorant Garamond`로 직접 표기, 항목명 막대 아래.
- 프로세스 슬라이드: 완만한 곡선을 따라 흐르는 4단계 플로우. 유기 블롭 노드 1.8in×1.0in, 어스 톤 채움 + 옅은 확산 그림자, 0.55in 번호 배지. 커넥터 1.5pt 모스그린 곡선, 단계 사이 잎 일러스트.
- 타임라인 슬라이드: 줄기처럼 굽이치는 1.5pt 모스그린 곡선 축, 마일스톤은 0.4in 유기 원이 잎처럼 위아래 교차. 현재 시점은 테라코타 원 + 새싹 일러스트, 날짜 라벨 16pt 세리프 이탤릭.
