# 아카이벌 인덱스 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 아카이벌 인덱스 — 종이빛 베이지 캔버스에 세리프 + 등폭 혼합, 도서관 카드·아카이브 대장처럼 모든 다이어그램이 번호·라벨·룰 라인으로 색인되는 빽빽한 카탈로그 미감.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 모든 요소가 등폭 인덱스 번호(`01`·`02`·`A1`·`B2`)로 색인되고 가는 룰 라인이 질서를 만든다, (2) 본문은 세리프, 코드·수치는 등폭 — 도서관 카드 대장의 활자 혼합, (3) 강조색 없이 잉크 브라운 단색. 모든 다이어그램이 표·인덱스·번호 카탈로그처럼 읽힌다.

## 색
- 배경 `#EFE9DD` (종이빛 베이지)
- 카드/셀 표면 `#F6F2E8` (살짝 밝은 베이지) 또는 `#FBF8F0`
- 본문 잉크 `#33302A` (잉크 브라운), 보조 `#7A7468`
- 등폭 인덱스 번호 `#5A5448`
- 룰 라인·헤어라인 `#C9C0AC` (가는 룰), 강한 룰 `#9A9180`
- 빗금 해치 패턴 라인 `#33302A`
- 강조색 없음 — 강조는 잉크 브라운 솔리드 채움 한 칸 또는 굵기. 컬러 강조·그라디언트 금지.

## 타이포그래피
- 폰트: 본문 세리프 `Source Serif 4`(대체 `Georgia`), 코드·수치·인덱스 `IBM Plex Mono`(대체 `Courier New`). 한글은 `Pretendard`(세리프 자리), 한글 수치도 가독 위해 `Pretendard`.
- 슬라이드 타이틀: 26pt / Source Serif 4 600 / 자간 0
- 인덱스 번호: 13pt / IBM Plex Mono 500 / 자간 +4%
- 섹션 디바이더 번호: 120pt / IBM Plex Mono 300
- 표·셀 헤더: 11pt / Source Serif 4 600 / 자간 +8% / 소형 대문자(small caps 느낌)
- KPI 대형 수치: 44pt / IBM Plex Mono 400 / 잉크 브라운
- 본문: 16pt / Source Serif 4 400 / 행간 1.5 / 슬라이드당 8줄 이하(밀도 허용)
- 캡션·각주: 10pt / IBM Plex Mono 400 / 색 `#7A7468`

## 레이아웃 / 그리드
- **엄격 그리드(dense).** 좌우 여백 각 0.6in, 상하 0.5in. 14열 그리드, 좌측 0.9in을 등폭 인덱스 컬럼으로 고정.
- 모든 콘텐츠가 그리드·룰 라인에 스냅. 행은 가는 룰 `#C9C0AC`로 구획.
- 슬라이드 상단에 타이틀 + 우측 등폭 슬라이드 번호(`Fig. 03 / 24` 식).
- 한 슬라이드 핵심 메시지 1개, 표·인덱스 모듈 2~4개. 밀도가 정체성.

## 형태 / 질감
- 모서리 반경 0px(각진 셀·카드). 보더는 0.75pt 룰 라인.
- 그림자·그라디언트 전면 금지(종이는 평면).
- 강조 채움: 잉크 브라운 솔리드 `#33302A`(반전 텍스트 베이지) 또는 45° 빗금 해치(선 간격 0.06in).
- 아이콘 거의 안 씀 — 인덱스 번호·룰·해치가 시각 어휘. 쓴다면 1.25pt 가는 라인 아이콘 단색.

## 차트·데이터 시각화 (아카이브 대장 차트 — 도판 번호 + 잉크 단색)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 신문·학술 도판 미감 — 잉크 단색, 도판 번호, 세리프 각주.
- **데이터 색:** 강조색 없음. 막대는 무채움 윤곽(0.75pt 잉크 브라운 보더) 또는 45° 빗금 해치 채움. 강조할 막대 **1개만** 잉크 브라운 솔리드 채움. 다계열은 무채움/해치/솔리드 3단계 텍스처로 구별(색이 아닌 텍스처 인코딩). 무지개·컬러 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 반경 0px(각진). 베이스라인 0에서 정확히(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선 제거(또는 y축 주요 눈금 0.5pt `#C9C0AC` 2~3개). 차트 테두리 박스·배경 채움 제거. x·y축선 0.75pt `#9A9180`.
- **값 레이블:** 막대 끝/꼭짓점에 직접 표기. `IBM Plex Mono` 13pt 400, 색 잉크 브라운, 탭형 정렬(등폭이라 자연 정렬), 단위·자릿수 일관. 카테고리명 막대 아래 11pt Source Serif 4. 범례 박스 금지 — 계열명은 차트 옆 텍스처 견본(0.16in 사각) + 11pt 세리프 라벨.
- **도판 번호:** 모든 차트 좌상단에 등폭 도판 번호 `Fig. 1`·`Fig. 2`, 차트 하단에 세리프 캡션 + 출처 각주(10pt 등폭) 의무.
- **차트 타입 매칭:** 비교=윤곽/해치 막대, 추세=1pt 잉크 폴리라인(속 빈 원 마커, 면적 채움 없음), 비중=100% 누적 막대 1개(세그먼트를 무채움/해치/솔리드로 구별). 파이·3D·도넛 다중 금지(도넛 쓰면 단순 1개, 세그먼트 텍스처 구별).
- **출처:** 차트 하단 좌측 10pt IBM Plex Mono `#7A7468` 출처·단위 각주 의무.

## 다이어그램·컴포넌트 (인덱스/대장 색인 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며(div 블록 금지) **하나의 다이어그램 언어**를 공유한다 — 모든 노드/셀은 각진(반경 0px) 베이지 셀 + 0.75pt 룰 라인 보더, 등폭 인덱스 번호로 색인(`01`·`02`·`A1`…), 별도 화살표 커넥터 대신 룰 라인·번호 연속성이 흐름을 만든다, 강조는 잉크 브라운 솔리드 채움 한 칸 또는 빗금 해치.
- **프로세스 플로우:** 번호 매겨진 사각 셀(대장 행처럼, 높이 1.0in, 베이지 채움 + 0.75pt 룰 보더), 각 셀 좌측에 등폭 인덱스 번호(`01`·`02`…, 13pt) — 화살표 커넥터 없음, 번호 연속성과 셀 사이 0.04in 룰 라인이 순서를 만든다. 활성 단계 셀만 좌측 0.12in 잉크 브라운 솔리드 바.
- **타임라인:** 수직 인덱스 타임라인 — 좌측 0.9in 등폭 연도 컬럼(우정렬) + 1pt 세로 룰 + 우측 세리프 사건 텍스트. 마일스톤은 룰 위 0.12in 잉크 브라운 솔리드 사각 틱, 현재 시점만 솔리드 채움 + 등폭 라벨.
- **비교 레이아웃:** 카탈로그 다열 표 — 0.75pt 룰 라인 격자, 헤더 행만 11pt 세리프 소형 대문자(잉크 브라운 솔리드 채움 + 베이지 반전 텍스트), 수치 셀 우정렬 등폭, 우세 항목 셀만 빗금 해치. 좌측 인덱스 컬럼.
- **매트릭스 2×2:** 표 형식 2×2 — 0.75pt 룰 십자, 각 사분면에 인덱스 코드(`A1`·`A2`·`B1`·`B2`, 등폭 13pt 좌상단), 데이터 포인트는 0.16in 잉크 브라운 솔리드 원 + 옆 11pt 세리프 라벨. 축 라벨 바깥 11pt 소형 대문자.
- **계층/퍼널:** 들여쓰기 인덱스 트리 — 목차식 번호 체계(`1`·`1.1`·`1.1.1`), 각 레벨 들여쓰기 0.35in + 등폭 번호 + 세리프 라벨, 레벨 사이 가는 룰. 퍼널은 폭 비례 각진 사각 적층(무채움 윤곽, 강조 단만 해치).
- **KPI·스탯 카드:** 대장 행 카드 — 각진 베이지 셀(0.75pt 룰 보더), 좌측 등폭 코드(`KPI-01`) + 11pt 세리프 소형 대문자 라벨, 거대 44pt IBM Plex Mono 잉크 브라운 KPI 수치, 그 아래 13pt 등폭 델타(`+12.4`·`-3.1`, 색 없이 부호와 굵기로). 셀 우측 작은 룰 구획.
- **목차/섹션 디바이더/인용:** 목차는 등폭 번호 컬럼 + 세리프 항목명 + 우측 점선 리더(`....`) + 등폭 페이지 번호(도서 목차식). 디바이더는 베이지 배경 + 좌측 거대 120pt 등폭 섹션 번호 + 26pt 세리프 섹션명 + 그 아래 0.75pt 룰. 인용은 베이지 셀 + 좌측 등폭 코드 + 큰 세리프 풀쿼트 22pt(이탤릭) + 출처 각주.

## 전환 (PPT)
전환 없음(즉시 컷). 아카이브 대장은 정적 — 빌드 애니메이션 금지.

## 하지 말 것
- 컬러 강조·그라디언트·발광 — 강조는 잉크 브라운 솔리드 또는 빗금 해치뿐.
- 둥근 모서리, 그림자, 입체 효과 — 종이는 평면·각짐.
- 화살표 커넥터를 다이어그램에 — 흐름은 등폭 번호 연속성과 룰 라인이 만든다.
- 본문 전체를 등폭으로(이건 minimal-mono-note) — 본문은 세리프, 등폭은 인덱스·수치·코드에만.
- 이모지·클립아트·스톡 아이콘, 빌드 애니메이션.
- 슬라이드를 너무 비우기 — 빽빽한 대장 밀도가 정체성(단, 한 슬라이드 핵심 메시지는 1개).
- 차트 회귀: 3D 차트, 컬러 채색, 격자선 과다, 범례 박스, 잘린 y축, 파이/다중 도넛, 도판 번호·출처 각주 누락.

## 적용 예
- **표지:** 베이지 배경, 좌측 등폭 도큐먼트 코드(`DOC-2026 / REV.01`), 중앙 26pt 세리프 타이틀, 하단 0.75pt 룰 + 등폭 메타 행(날짜·작성·페이지 수).
- **본문 슬라이드:** 좌측 0.9in 등폭 인덱스 컬럼(`01`~`05`), 우측 세리프 본문 행을 룰 라인으로 구획, 핵심 행만 빗금 해치 강조.
- **차트 슬라이드:** 좌상단 `Fig. 1` 등폭 라벨 + 윤곽/해치 막대 차트(강조 1막대 솔리드, 등폭 13pt 값 라벨, x·y축 0.75pt), 우측 100% 누적 막대(세그먼트 텍스처 구별) + 10pt 출처 각주.
- **프로세스 슬라이드:** 번호 매겨진 대장 행 셀 5개(좌측 `01`~`05` 등폭, 화살표 없이 룰 라인 연속), 활성 단계만 좌 솔리드 바.
- **타임라인 슬라이드:** 수직 인덱스 타임라인 — 좌측 등폭 연도 컬럼 + 1pt 세로 룰 + 우측 세리프 사건, 솔리드 사각 틱 마일스톤.
- **매트릭스 슬라이드:** 표 형식 2×2 룰 십자 + 사분면 인덱스 코드 `A1`~`B2`, 잉크 브라운 솔리드 원 데이터 포인트.
