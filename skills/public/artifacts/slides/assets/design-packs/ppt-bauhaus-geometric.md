# 바우하우스 지오메트릭 — ppt 디자인 팩

## 이 스타일의 정체성
1920년대 바우하우스 조형 원리를 슬라이드로 옮긴다. 원·삼각형·사각형의 순수 기본 도형, 빨강·노랑·파랑 삼원색에 검정·흰색만. form follows function의 기하 구성 — 도형이 겹치고 대각으로 가로지르며 비대칭 균형을 이룬다. 한눈에 "체계적 기하 추상"으로 식별된다(멤피스의 무작위 키치와 정반대로 질서 있다).

## 색
- 배경: `#F0EDE4`(오프화이트). 또는 도형이 배경 자체일 때 흰색 `#FFFFFF`.
- 텍스트: `#1A1A1A`(잉크 블랙).
- 삼원색만: `#D62828`(바우하우스 레드), `#F4C20D`(바우하우스 옐로), `#1D4ED8`(바우하우스 블루). 이 3색 + 검정 + 흰색 외 어떤 색도 금지.
- 한 슬라이드에 삼원색 중 2~3색 사용, 단색 플랫 채움.
- 그라디언트·중간색·파스텔 절대 금지.

## 타이포그래피
- 헤드라인: `Futura` 또는 `Archivo Black` (대체: `Pretendard ExtraBold`, sans-serif) — 기하 산세리프. 표지 50pt, 본문 제목 36pt. 자간 0.
- 본문: `Inter` 또는 `Pretendard` Regular 24pt, 행간 1.4. 슬라이드당 6줄 이하.
- 캡션: `Inter` Medium 15pt, 대문자, 자간 0.1em.
- 제목은 수평 또는 정확히 90도 수직 회전만 허용 — 임의 기울임 금지(멤피스와 차별점).

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 좌우 여백 각 0.7in, 상하 각 0.6in.
- 기하 구성 그리드: 캔버스를 도형으로 분할한다. 큰 도형 블록 1개가 슬라이드의 1/3~1/2를 점유.
- 비대칭 균형 — 한쪽 큰 도형을 반대편 작은 도형 군집과 시각 무게로 맞춘다.
- 대각선 구성: 슬라이드마다 하나의 대각 축(도형 정렬 또는 사선 분할)을 둔다.

## 형태 / 질감
- 도형: 정원·정삼각형·정사각형/직사각형만. 반원·1/4원 허용. 자유 곡선·블롭 금지.
- 도형 겹침: 도형들이 겹쳐 새 면을 만든다. 겹친 부분은 다른 삼원색으로.
- 보더: 검정 2pt 솔리드를 일부 도형 외곽에. 또는 보더 없는 플랫 면.
- 그림자 전무 — 깊이는 겹침 순서로만.
- 모서리 반경 0(사각형)·완전 원(원형). 중간 라운드 금지.
- 이미지: 사용 시 원·삼각형·사각형 마스크로 클리핑.

## 전환 (PPT)
- 전환 없음(None) 또는 즉시 컷 — 정적 구성. 도형 등장은 Wipe(방향성 있게) 허용, 0.3s. Bounce·Fade 금지.

## 하지 말 것
- 삼원색·검정·흰색 외 색 금지. 그라디언트·중간색·파스텔 금지.
- 자유 곡선·블롭·물결 도형 금지 — 원·삼각형·사각형 순수 도형만.
- 도형을 임의 각도로 기울이지 말 것 — 0/90/45도 정렬만(멤피스와 차별점).
- 그림자·둥근 모서리 카드 금지.
- 이모지·스톡 아이콘·일러스트 금지. 모든 시각 요소는 기본 도형 구성.
- 슬라이드를 텍스트로 가득 채우지 말 것 — 도형 구성에 공간을 내준다.
- **차트 금지사항(아마추어 회귀 차단):** 3D·입체 막대·원근 파이 금지. 그림자(하드·소프트 모두) 금지. 격자선 금지. 범례 박스 금지 — 직접 레이블링만. 삼원색 외 색·중간색·파스텔 금지. 둥근 막대 금지(직각만). 잘린 y축 금지. 데이터 영역 테두리 박스 금지. div·표 셀 막대 금지 — SVG 정밀 렌더.

## 차트·데이터 시각화
바우하우스 차트 = 기하 원색 막대 + 체계적 구성. 차트는 기하 추상 구성의 한 형태로 다룬다 — 막대 자체가 사각형 도형, 도넛은 원, 비례는 정원 크기로.
- **렌더링:** SVG로 정밀하게 그린다. 막대 폭 : 간격 = 3 : 2, 모서리 반경 0(직각 사각형). 막대 하단 기준선은 값 0에 정확히 정렬. 잘린 y축 절대 금지.
- **축·격자:** 격자선 완전 제거. x축(기준선)만 검정 2pt 솔리드 라인 `#1A1A1A`. y축선 제거(또는 검정 2pt 1개). 눈금 라벨 최소(0·최댓값).
- **데이터 색:** `tokens.json`의 `color.chart` 삼원색(`#D62828`·`#F4C20D`·`#1D4ED8`)을 막대에 순환 평면 채움. 비교에서 핵심 막대 1개는 빨강 `#D62828` 고정. 단일 계열 강조가 필요하면 나머지 막대를 검정 `#1A1A1A`로 두고 강조 1개만 원색. 일부 막대에 검정 2pt 외곽선 허용.
- **값 레이블:** 막대 위 직접 표기. `Inter` Medium 15pt 대문자 자간 0.1em `#1A1A1A`, 탭형 정렬, 일관된 자릿수·단위 — 캡션 활자와 동일 스타일.
- **직접 레이블링:** 범례 박스 금지. 항목명은 막대 아래 15pt 대문자 캡션으로 직접 붙인다.
- **차트 타입:** 비교=직각 막대(삼원색 순환 또는 검정+원색 강조 1). 비중=도넛(조각 3개 이하, 삼원색, 중앙 정원에 핵심 수치 `Futura` 36pt) 또는 원형 비례를 정원 도형 크기 차이로 직접 표현(정원 면적 = 데이터값). 추세=2pt 직선 꺾은선(원색). 파이 4조각+·다중 도넛 금지.

## 다이어그램·컴포넌트
바우하우스 다이어그램 = 순수 기본 도형(원·삼각형·사각형) 노드 + 검정 2pt 직선 커넥터 + 정원 번호 배지. 다이어그램도 기하 추상 구성의 한 형태 — 노드 자체가 도형이고, 단계는 도형 종류 또는 삼원색으로 구분한다. 모든 다이어그램이 한 언어를 공유한다 — 노드 도형은 정원/정사각형/정삼각형만, 커넥터는 검정 2pt 솔리드 직선(0/45/90도만), 번호 배지는 정원, 강조는 빨강 `#D62828` 고정. 전부 SVG 정밀 렌더, div 블록 금지.
- **공통 다이어그램 언어:** 노드 = 정원(지름 1.4in)·정사각형(한 변 1.4in)·정삼각형 중 택일, 단색 삼원색 평면 채움, 일부 검정 2pt 외곽선. 커넥터 = 검정 2pt 솔리드 직선, 각도는 0/45/90도만, 화살촉은 정삼각형 변 0.18in. 번호 배지 = 지름 0.4in 정원, 검정 채움 + 흰색 숫자 `Futura` 18pt. 강조 노드만 빨강 `#D62828`.
- **프로세스 플로우:** 4~5단계, 노드는 정사각형(한 변 1.4in) 또는 정원, 삼원색 순환 채움. 노드 간격 0.5in을 검정 2pt 직선(수평) + 정삼각형 화살촉으로 연결. 각 노드 위에 정원 번호 배지, 노드 아래 15pt 대문자 캡션. 활성 단계 1개만 빨강 `#D62828`, 나머지 노드는 검정 2pt 외곽선 + 노랑/파랑.
- **타임라인:** 수평 축 = 검정 2pt 솔리드 직선. 마일스톤 마커 = 축 위 지름 0.5in 정원(삼원색 순환), 축에서 0.6in 올린 위치에 15pt 대문자 날짜 + 24pt 헤드라인. 현재 시점만 빨강 정원 + 그 위 겹친 노랑 정삼각형. 마커 간격은 날짜 비례. 축 한쪽 끝에 작은 정삼각형 종점 표시.
- **비교 레이아웃:** 2~3열 대조, 12열을 6+6 또는 4+4+4 균등 분할. 각 열 상단에 큰 도형 1개(열마다 다른 삼원색·다른 도형 — 사각/원/삼각), 그 아래 36pt 헤드라인 + 15pt 대문자 캡션 항목. 열 구분은 검정 2pt 세로 직선만. vs 표기는 열 사이 겹친 빨강 원 + 검정 2pt 외곽.
- **매트릭스 2×2:** 정사각 사분면, 한 변 4.4in. 사분면 구분은 검정 2pt 십자 직선. 각 사분면은 옅은 삼원색 평면 채움 가능(택1, 오프화이트와 충돌 없게). 축 라벨 = 끝에 15pt 대문자 자간 0.1em. 데이터 포인트 = 지름 0.4in 정원(삼원색), 핵심 포인트 1개만 빨강 `#D62828` + 검정 2pt 외곽선.
- **계층/퍼널:** 수직 적층 — 계층은 사각형 단을 위→아래로 폭 축소(폭 차이 1.4in씩, 높이 0.9in 균등), 퍼널은 정삼각형을 거꾸로 세워 가로 슬라이스로 분할. 각 단 삼원색 순환 채움, 좌측에 정원 번호 배지, 내부 24pt 헤드라인. 정점/병목 단 1개만 빨강.
- **KPI·스탯 카드:** 카드 = 한 변 2.6in 정사각형, 옅은 삼원색 또는 흰색 평면 채움 + 검정 2pt 외곽선. 좌상단에 작은 정원/정삼각형 도형 액센트, 거대 수치 50pt `Futura` 검정, 그 아래 15pt 대문자 라벨. 증감은 정삼각형(위=증가 파랑, 아래=감소 빨강) + 수치. 카드 3개는 12열 4+4+4 균등, 간격 0.25in.

## 적용 예
- 표지: 오프화이트 배경, 좌측 1/2을 채우는 큰 파랑 사각형, 그 위에 겹친 빨강 원과 노랑 삼각형, 우측에 50pt 검정 제목. 대각 축은 좌하→우상.
- 본문: 좌상단 작은 빨강 정사각형 + 36pt 제목, 본문 6줄, 우하단에 노랑 반원 + 파랑 정원 군집(비대칭 무게 균형).
- 차트: SVG 직각 막대 차트. 막대 폭:간격 = 3:2, 모서리 0. 막대는 `color.chart` 삼원색 순환 평면 채움, 핵심 막대 1개는 빨강 `#D62828`(또는 검정 막대들 + 원색 강조 1). 격자선·범례 제거, x축만 검정 2pt, 기준선 0. 값 레이블 15pt `Inter` 대문자 자간 0.1em 직접 표기. 또는 원형 비례를 정원 도형 크기로 표현.
- 다이어그램(프로세스): SVG 4단계 플로우. 정사각형/정원 노드(한 변 1.4in) 삼원색 순환 채움, 검정 2pt 직선 + 정삼각형 화살촉 연결. 노드 위 정원 번호 배지, 활성 단계 1개만 빨강 `#D62828`.
- 다이어그램(타임라인): SVG 수평 타임라인. 검정 2pt 축 + 지름 0.5in 정원 마일스톤 마커(삼원색 순환), 15pt 대문자 날짜 라벨. 현재 시점만 빨강 정원 + 겹친 노랑 정삼각형.
