# Blueprint Schematic Deck — ppt 디자인 팩

## 이 스타일의 정체성
딥 인디고-블루 배경에 1px 시안 헤어라인 도트 그리드가 청사진처럼 전면 노출되고, 모든 콘텐츠가 그 격자에 스냅한다. 흰색 가는 산세리프 + 등폭 숫자, 도형은 채움 없는 0.75pt 라인 드로잉이다. 치수 보조선·인출선·45° 단면 해치·노스 애로우·스케일 바를 정보 장식으로 차용해 "엔지니어링 도면" 미감을 만든다 — 네온 사이버가 아니라 제도판 위 청사진이다.

## 색
- 배경 `#0E1B3D` 딥 인디고-블루 (전 슬라이드 동일).
- 도트 그리드·보조선 `#2A4A8C` (1px, 청사진 격자).
- 라인 드로잉·보더 시안 `#4FC8E8` (0.75pt, 채움 없음).
- 본문 텍스트 `#E8EEF7` (오프화이트), 보조 텍스트 `#8FA3C8`.
- 강조색은 시안 `#4FC8E8` 1색 — 강조 막대·활성 노드·현재 시점 글로우에만 채움으로 사용.
- 해치 패턴 라인 `#3A5DA0` (45° 0.75pt).

## 타이포그래피
- 폰트: 라틴 본문 **Inter Light/Regular**, 한글 **Pretendard Light/Regular**, 숫자·코드 **JetBrains Mono** 또는 **IBM Plex Mono** (모두 공개 폰트). 대체 `Arial`, `Noto Sans KR`, `Courier New`.
- 표지 제목 38pt / Inter Light / 자간 0.02em / 행간 1.2.
- 슬라이드 제목 24pt / Inter Regular / 자간 0.03em.
- 본문 18pt / Inter Light / 행간 1.4 / 슬라이드당 6줄 이하.
- 다이어그램 라벨 13pt / Inter Regular / 자간 0.04em.
- 수치·치수·좌표 14pt / **JetBrains Mono Regular** (등폭, tabular).
- 캡션·타이틀 블록 텍스트 10pt / Inter Regular / `#8FA3C8`.
- 한글과 등폭 숫자가 한 줄에 섞일 때: 한글은 Pretendard, 숫자만 모노 — 폭 불일치를 피하려 숫자는 별도 라벨 칸으로 분리한다.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 좌우 여백 각 0.55in, 상하 여백 각 0.45in.
- 전면 도트 그리드: 0.4in 간격, 0.7px 점 `#2A4A8C`. 모든 도형·텍스트가 격자 노드에 스냅.
- 슬라이드 외곽에 0.75pt 시안 도면 테두리 프레임 + 네 모서리 코너 크롭 마크.
- 우하단에 도면 표제란(타이틀 블록): 0.75pt 시안 박스, 슬라이드 번호·제목·"SHEET XX/XX" 등폭 표기.
- 좌하단에 스케일 바 또는 노스 애로우(정보 장식).

## 형태 / 질감
- 모든 도형 채움 없음 — 0.75pt 시안 윤곽선 라인 드로잉만. 강조 도형만 시안 채움.
- 모서리 반경 0px.
- 커넥터는 직각 꺾임 배선(라우팅 라인) + 삼각 화살촉.
- 치수선: 양끝 화살표 캡 + 보조선(extension line). 인출선(leader): 가는 사선 + 끝 원형 말풍선.
- 그림자·그라디언트·둥근 모서리 없음.

## 전환 (PPT)
- 전환 없음(`none`). 컷 전환 — 제도 도면의 정적 정밀함이 정체성.

## 차트·데이터 시각화
차트도 엔지니어링 도면처럼 — 채움 없는 윤곽선, 등폭 수치, 좌표 눈금.
- **막대 차트.** 채움 없는 0.75pt 시안 윤곽 막대. 강조 막대 1개만 시안 `#4FC8E8` 채움, 나머지는 윤곽선만. 막대:간격 = 3:2. y축은 좌표 눈금(치수선 스타일, 등폭 라벨), 격자선은 도트 그리드가 대신 — 추가 격자 없음. x 베이스라인 0.75pt 시안.
- **라인 차트.** 1px 시안 폴리라인, 꼭짓점에 0.1in 속 빈 원 마커. 면적 채움 없음(강조 구간만 시안 10% 채움). 값은 꼭짓점 위 등폭 14pt 직접 라벨.
- **값 레이블.** 모두 JetBrains Mono 14pt, tabular, 막대·꼭짓점 위 직접 표기. 단위는 축 끝 등폭 라벨.
- **비중.** 도넛 대신 100% 누적 막대(세그먼트 채움 없는 윤곽, 강조 1칸 시안 채움) 또는 좌표 산점.
- **금지.** 무지개색·범례 박스·3D·격자선 과다·면 채움 그라디언트.
- 모든 차트 SVG 정밀 렌더 — div 블록 금지. 우하단 표제란 또는 좌하단 출처 등폭 캡션.

## 다이어그램·컴포넌트
모든 다이어그램은 채움 없는 0.75pt 시안 라인·직각 배선 커넥터·인출선 라벨·등폭 수치라는 한 언어를 공유한다.
- **프로세스 플로우.** 무채움 0.75pt 시안 보더 사각 노드(높이 0.85in). 노드 사이 직각 꺾임 배선 커넥터 + 삼각 화살촉. 단계 번호는 인출선 끝 원형 말풍선(지름 0.34in, 0.75pt 시안 보더, 등폭 숫자 14pt). 활성 노드만 시안 12% 채움.
- **타임라인.** 수평 치수선 — 양끝 화살표 캡 + 보조선. 마일스톤은 보조선(extension line)으로 위치 표시 + 등폭 날짜 라벨. 현재 시점 마커만 시안 글로우(시안 외곽 12% 채움 원).
- **비교 레이아웃.** 2열 — 두 열을 45° 단면 해치 패턴 밀도 차이로 구별(좌열 성김, 우열 빽빽 또는 그 반대). 각 열 상단에 타이틀 블록 헤더(0.75pt 시안 박스 + 등폭 코드). 항목 행은 도트 그리드 정렬.
- **매트릭스 / 2×2.** 눈금·치수가 표기된 좌표축(0.75pt 시안, 양 축에 등폭 눈금 라벨). 데이터 마커는 십자 타겟(crosshair, 0.1in 십자 + 작은 원). 사분면 라벨은 모서리 등폭 코드.
- **계층 / 단면도.** 적층 단면도 — 각 레벨을 45° 해치 밀도 변화로 구별(아래 레이어일수록 빽빽). 레벨 라벨은 우측 인출선 + 등폭 코드.
- **KPI·스탯 카드.** 도면 표제란 박스 형태 — 0.75pt 시안 박스를 작은 칸으로 분할, 한 칸에 거대 등폭 수치(40pt JetBrains Mono), 다른 칸에 13pt 라벨 + 등폭 코드. 슬라이드당 3~4개.
- **목차 / 섹션 디바이더.** 목차는 도면 시트 인덱스 형태 — "SHEET 01 … SHEET NN" 등폭 리스트 + 우측 시안 라인. 디바이더는 거대 등폭 섹션 번호 + 노스 애로우 + 스케일 바 장식.
- 모든 다이어그램 SVG 정밀 렌더 — div 블록 금지.

## 하지 말 것
- 네온 사이버펑크 톤 금지 — 발광 글로우 남발, 형광 마젠타·퍼플, 디지털 글리치 효과 금지. 이것은 제도판 위 청사진이지 SF UI가 아니다.
- 도형에 솔리드 면 채움 금지 — 0.75pt 시안 윤곽선만. 강조 1개만 시안 채움 허용.
- 도트 그리드를 끄지 말 것 — 모든 슬라이드에 전면 노출이 정체성.
- 둥근 모서리·드롭 섀도·그라디언트 금지.
- 수치를 일반 산세리프로 쓰지 말 것 — 모든 수치·치수·좌표는 등폭(JetBrains Mono/IBM Plex Mono).
- 무지개 차트·범례 박스·격자선 과다 금지.
- 이모지·클립아트·스톡 아이콘 금지 — 아이콘은 라인 드로잉으로.

## 적용 예
- **표지.** 딥 인디고 캔버스, 전면 도트 그리드, 외곽 도면 프레임 + 코너 크롭. 중앙 좌측 38pt Light 제목, 그 아래 등폭 부제. 우하단 타이틀 블록에 "SHEET 01" 발표 정보.
- **본문(스테이트먼트).** 상단 24pt 제목 + 본문 4줄. 우측에 채움 없는 라인 드로잉 다이어그램 1개 + 인출선 라벨.
- **프로세스 다이어그램 슬라이드.** 무채움 시안 사각 노드 5개 + 직각 배선 커넥터 + 삼각 화살촉, 인출선 끝 원형 말풍선 번호 01~05, 활성 노드 시안 12% 채움.
- **타임라인 다이어그램 슬라이드.** 수평 치수선(양끝 화살표 캡), 보조선 마일스톤 5개 + 등폭 날짜, 현재 시점만 시안 글로우 원.
- **매트릭스 다이어그램 슬라이드.** 눈금 좌표축 2×2, 데이터 마커 6개를 십자 타겟으로, 사분면 모서리 등폭 코드, 좌측 해설.
- **차트 슬라이드.** 채움 없는 윤곽 막대 6개, 4번 막대만 시안 채움, 막대 위 등폭 14pt 값, x 베이스라인 시안, y축 좌표 눈금, 우하단 표제란.
- **KPI 슬라이드.** 도면 표제란형 분할 박스 3개 — 한 칸 거대 등폭 수치, 한 칸 라벨+코드, 좌하단 스케일 바.
