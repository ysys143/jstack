# 헤리티지 럭셔리 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 따뜻한 세피아-샴페인 톤에 옅은 골드 헤어라인 한 줄로 격을 내는, 헤리티지·럭셔리 브랜드 IR/소개용 덱 — 중앙 정렬 축과 광활한 여백의 격식.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 배경이 따뜻한 샴페인 `#EDE6D6`, 텍스트는 다크 브라운 `#3A2E1F` — 흑백이 아닌 세피아 세계. (2) 하이콘트라스트 디돈 계열 세리프 디스플레이가 화면 중앙에 크게 앉고, 본문은 절제된 휴머니스트 세리프. (3) 모든 슬라이드에 골드 `#A8893E` 헤어라인 한 줄(0.75pt)이 격을 만들고, 중앙 정렬 축 양옆으로 여백을 크게 비운다.

## 색
- 배경 `#EDE6D6` (따뜻한 샴페인 — 순백 금지, 그라디언트·텍스처 금지)
- 표면/카드 면 `#F4EFE3` (샴페인보다 한 톤 밝음, 그림자 없이 면 대비로만)
- 1차 텍스트 `#3A2E1F` (다크 세피아 브라운, 순흑 아님)
- 보조 텍스트·캡션 `#8A7C63` (웜 토프)
- 헤어라인·룰·구분선 `#A8893E` (옅은 골드, 0.75pt) — 격식의 핵심 디바이스
- 강조색 **1개만**: `#A8893E` (옅은 골드) — 헤어라인, 핵심 수치, 차트 데이터, 키 워드 1어절에만. 본문 텍스트엔 컬러 금지.

## 타이포그래피
- 디스플레이 폰트(디돈 세리프): `Playfair Display` (대체 `Bodoni Moda`, `Didot`). 한글 병기 시 `Noto Serif KR`.
- 본문 폰트(휴머니스트 세리프): `EB Garamond` (대체 `Cormorant`, `Georgia`). 한글 병기 시 `Noto Serif KR`.
- 표지 제목: 52pt / Playfair Display / Regular(400) / 자간 +0.5% / 행간 1.12 / 최대 2줄 / 중앙 정렬
- 슬라이드 헤딩: 34pt / Playfair Display / Regular(400) / 자간 +0.5% / 행간 1.2 / 중앙 정렬 / 최대 2줄
- 키커/오버라인: 11pt / EB Garamond / Regular(400) / 대문자 / 자간 +18% / 색 `#8A7C63` / 중앙 정렬
- 본문: 17pt / EB Garamond / Regular(400) / 행간 1.6 / 슬라이드당 최대 6줄
- KPI 대형 숫자: 56pt / Playfair Display / Regular(400) / 색 `#A8893E`
- 캡션·출처: 10pt / EB Garamond / Italic / 색 `#8A7C63`

## 레이아웃 / 그리드
- **중앙 정렬 축 그리드.** 좌우 여백 각 1.2in, 상하 각 0.9in. 콘텐츠는 캔버스 중앙선을 기준으로 대칭.
- 헤딩 영역: 상단 0.9~2.0in. 키커(헤딩 위) → 0.75pt 골드 헤어라인 짧은 1줄(폭 0.6in, 중앙) → 헤딩 순. 또는 헤딩 아래 골드 헤어라인.
- 본문 콘텐츠: 2.3in부터 6.3in까지. 최대 텍스트 폭 8.0in(중앙 정렬, 양옆 여백 크게). 2~3열 카드는 각 열이 중앙 축에 대칭.
- 카드: `#F4EFE3` 면, 보더 없음 또는 0.75pt `#A8893E` 헤어라인. 내부 패딩 0.3in.
- 하단 중앙에 슬라이드 번호 10pt 이탤릭. 출처는 우하단 10pt 이탤릭.

## 형태 / 질감
- 모서리 반경 0px(직각 — 격식). 그림자 전면 금지. 그라디언트·글로우 금지.
- 골드 헤어라인은 0.75pt 균일. 골드를 면 채움으로 크게 쓰지 않는다(헤어라인·세선·작은 수치에만 — 절제가 럭셔리).
- 아이콘은 1pt 스트로크 라인 아이콘만, 단색 `#3A2E1F`, 채움 금지. 슬라이드당 3개 이하.
- 이미지는 세피아 듀오톤 처리(`#3A2E1F`+`#EDE6D6`), 직각 크롭, 보더 없음 또는 0.75pt 골드 헤어라인 프레임.

## 차트 / 데이터 시각화 (럭셔리 — 헤어라인 라인 + 골드 단색, 광활한 여백)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 이 팩의 차트는 "데이터가 우아하게 숨 쉬는, 헤어라인으로 그린 그래픽"이다 — 차트도 절제로 격을 낸다.
- **차트 영역(절대값):** 플롯 영역 가로 약 7.0in × 세로 약 3.0in, 캔버스 중앙. 차트 양옆·위아래로 여백을 크게 비운다(여백이 럭셔리의 본질). 모든 막대·점·축은 픽셀 단위 정렬.
- **차트 타입 매칭:** 시계열 추세=가는 라인(이 팩의 기본 — 가장 우아함), 비중=미니멀 도넛(조각 3개 이하, 중앙에 56pt 핵심 수치), 항목 비교=가는 막대(소수 항목). 막대보다 라인·도넛을 우선. 파이 5조각 이상·3D·면적 채움 차트 금지.
- **데이터 잉크 최소화:** 차트 테두리 박스·배경 채움·범례 박스 제거. 격자선 전면 제거(럭셔리 차트엔 격자선이 노이즈). y축 눈금 라벨 생략 — 값은 직접 레이블로만.
- **축:** x축 기준선만 0.5pt `#A8893E` 헤어라인(또는 축선도 생략). y축선 생략. **막대·라인 기준선은 데이터 0에서 시작**(잘린 y축 금지).
- **직접 레이블링:** 카테고리 이름을 각 막대·점 아래 11pt EB Garamond `#8A7C63`. 값 레이블은 막대 끝/꼭짓점 위 0.08in에 13pt EB Garamond, 강조 데이터 값만 `#A8893E`·나머지 `#3A2E1F`, 자릿수·단위 일관, 탭형 정렬. 축 라벨 세리프(`EB Garamond`).
- **데이터 색:** 강조할 데이터 1개만 골드 `#A8893E`, 나머지는 `#C4B79A`(연한 세피아). 무지개·계열별 다른색 금지. 계열이 둘이면 `#A8893E` + `#8A7C63` 두 톤만.
- **라인 차트(기본):** 1pt 헤어라인 실선(가늘게 — 우아함), 강조 계열 `#A8893E`·보조 `#C4B79A`, 마커는 끝점·강조점에만 지름 5px 원(채움 `#A8893E`, 1px `#EDE6D6` 테두리). 면적 채움 없음. 직선 세그먼트.
- **가는 막대:** 막대 폭 : 간격 = 2 : 3(가늘고 여백 넓게). 모서리 반경 0px. 외곽선 없음, 솔리드 채움.
- **도넛:** 링 두께 가늘게(반지름의 약 18%), 조각 3개 이하, 강조 조각만 `#A8893E`·나머지 `#C4B79A`, 중앙에 56pt Playfair Display 핵심 수치. 3D·다중 링 금지.
- **헤딩 + 출처:** 차트 슬라이드도 상단 34pt 디돈 세리프 헤딩 의무. 차트 하단에 단위 명기, 우하단 10pt 이탤릭 출처 캡션 의무.

## 다이어그램·컴포넌트 (럭셔리 — 골드 헤어라인으로 그린, 여백이 숨 쉬는 도식)
다이어그램은 전부 SVG로 정밀 렌더한다(div 블록 금지). 이 팩의 다이어그램 언어는 차트와 동일하다 — **0.75pt 골드 `#A8893E` 헤어라인 골격, 면 채움 없음(또는 `#F4EFE3` 한 톤), 직각 0px, 활성 1개만 골드 강조, 양옆으로 여백을 크게 비운다**. 골드를 큰 면 채움으로 쓰지 않는다(절제가 럭셔리) — 노드 테두리·세선·작은 마커에만. 화살촉은 가는 V자(채움 없음, 폭 0.09in). 단계 번호는 동일 배지로: 지름 0.36in 원, 0.75pt `#A8893E` 헤어라인 테두리, 채움 없음, 안에 `Playfair Display` 16pt `#3A2E1F` — 활성 단계만 원·숫자 `#A8893E`. 모든 다이어그램은 중앙 정렬 축에 대칭 배치.
- **프로세스 플로우:** 수평 단계 노드, 노드 = 채움 없음 또는 `#F4EFE3` 면 + 0.75pt `#A8893E` 헤어라인 테두리, 폭 1.9in × 높이 0.95in, 0px 반경, 내부 패딩 0.3in. 노드 위 중앙에 0.36in 원형 번호 배지, 노드 안 중앙 정렬 17pt `EB Garamond` 라벨 + 11pt `#8A7C63` 보조. 커넥터 = 0.75pt `#A8893E` 헤어라인 + 가는 V자 화살촉. 노드 간격 0.5in(여백 넓게). 최대 4단계, 활성 단계만 테두리·번호 `#A8893E`.
- **타임라인:** 수평 0.75pt `#A8893E` 골드 헤어라인 축선 1줄, 캔버스 중앙. 마일스톤 마커 = 지름 7px 원, 채움 없음 + 0.75pt `#A8893E` 테두리(현재/핵심 시점만 `#A8893E` 채움). 마커 위 11pt `EB Garamond` 대문자 날짜(자간 +18%), 마커 아래 17pt `Playfair Display` 이벤트명. 마커 5개 이하, 등간격, 양 끝 여백 크게.
- **비교 레이아웃:** 2~3열 대조, 중앙 축 대칭. 열 사이 0.75pt `#A8893E` 골드 수직 헤어라인. 각 열 상단 11pt `EB Garamond` 대문자 키커 → 폭 0.6in 골드 헤어라인(중앙) → 17pt 본문(중앙 정렬). 열 배경 채움 없음. vs 표기는 두 열 사이 중앙에 작은 골드 ◆ 또는 `Playfair Display` Italic "vs".
- **매트릭스 / 2×2:** 가로·세로 축선 각 0.75pt `#A8893E` 골드 헤어라인 십자, 캔버스 중앙, 양옆 여백 크게. 사분면 채움 없음(헤어라인 격자만 — 절제). 축 라벨 11pt `EB Garamond` 대문자, 사분면명 17pt `Playfair Display`. 데이터 포인트 = 지름 0.16~0.4in 원, 채움 없음 + 0.75pt `#A8893E` 테두리, 강조 1개만 `#A8893E` 채움. 점 옆 11pt `EB Garamond` 라벨.
- **계층 / 피라미드 / 퍼널:** 3~4레벨, 위→아래 폭이 변하는 사다리꼴, 면 채움 없음(헤어라인 윤곽만) 또는 `#F4EFE3` 한 톤, 0.75pt `#A8893E` 윤곽선. 레벨 사이 0.12in 간격. 레벨 라벨 도형 안 중앙 정렬 17pt `EB Garamond` + 우측 여백에 11pt `#8A7C63`. 정점·핵심 1레벨만 윤곽 `#A8893E` 강조 또는 그 안 56pt 골드 KPI 숫자.
- **KPI·스탯 카드:** `#F4EFE3` 면 또는 채움 없음 + 0.75pt `#A8893E` 헤어라인(상단 또는 1면), 0px 반경, 내부 패딩 0.3in, 중앙 축 대칭 배치. 구성 = 11pt `EB Garamond` 대문자 키커(중앙) → 56pt `Playfair Display` 골드 수치 → 17pt `EB Garamond` 설명. 증감은 수치 아래 11pt `EB Garamond` Italic + 가는 ▲/▼(▲ `#A8893E` / ▼ `#8A7C63` — 절제). 카드 2~3열, 사이 간격 넓게(0.3in 이상).

## 전환 (PPT)
느리고 우아한 페이드 — 0.4~0.5s 크로스 디졸브. 텍스트는 0.4s 페이드 인까지 허용. 날아오기·줌·회전·바운스 금지.

## 하지 말 것
- 배경을 순백 `#FFFFFF`나 회색으로 — 반드시 샴페인 `#EDE6D6`.
- 텍스트를 순흑 `#000000`으로 — 다크 세피아 브라운 `#3A2E1F`.
- 강조색 2개 이상, 골드를 큰 면 채움으로 쓰기(헤어라인·세선·작은 수치에만), 본문 텍스트에 컬러.
- 디스플레이에 산세리프 쓰기 — 디스플레이=디돈 세리프, 본문=휴머니스트 세리프 고정.
- 둥근 모서리, 그림자, 그라디언트, 글로우.
- 좌측 정렬로 빽빽하게 — 콘텐츠는 중앙 정렬 축, 양옆 여백을 크게 비운다.
- **아마추어 차트 회귀 금지:** 3D·입체 막대, 막대 그림자·광택·베벨, 무지개·계열별 색칠, 격자선, 차트 테두리 박스, 배경 채움, 범례 박스, 잘린 y축, div 블록 막대, 면적 채움 그래프, 굵은 막대.
- 이모지 불릿·클립아트·스톡 아이콘·특정 명품 브랜드의 모노그램·패턴 재현.
- 슬라이드를 6줄 넘는 글로 채우기.

## 적용 예
- **표지:** 샴페인 배경, 중앙 정렬 — 상단 11pt 키커, 폭 0.6in 골드 헤어라인 1줄(중앙), 52pt Playfair Display 제목 2줄, 그 아래 17pt EB Garamond 부제 1줄. 하단 중앙에 날짜·작성처 10pt 이탤릭.
- **본문 슬라이드:** 키커 + 골드 헤어라인 + 34pt 디돈 세리프 헤딩(전부 중앙 정렬). 아래 3열 `#F4EFE3` 카드(중앙 축 대칭), 각 카드 17pt 본문 4줄 + 56pt 골드 KPI 숫자. 우하단 출처.
