# 한국 정책보고서 네이비 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 한국 정부·공공기관 정책보고서 미감 — 상단 네이비 헤더바, 굵은 한국어 고딕 타이틀, 좌측 번호 매긴 섹션, 정렬된 박스형 본문.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 슬라이드 상단 12% 높이의 네이비 헤더바에 흰 타이틀, (2) 본문 섹션마다 좌측에 번호 칩(①②③ 또는 01·02·03), (3) 본문은 KRDS 파랑 헤어라인으로 구획된 정돈된 박스. 공식 문서의 단정함이 핵심.

## 색
baseline(평면 네이비 PPT)과 색만으로 구별되려면 단조로운 네이비 단색에서 벗어나야 한다. KRDS(디지털플랫폼정부 디자인시스템)의 **실제 팔레트 체계** — 주색 1 + 포인트 컬러 2 + 정보 틴트 1 — 로 재정의한다.
- 배경 `#FFFFFF`
- **주색 네이비** `#0B2C5C` — 헤더바·장 번호·섹션 헤딩에만. 면적을 키우지 않는다(헤더바 12%가 상한).
- **링크/주 액션 블루** `#1B66C9` — 번호 칩·키워드 강조·차트 주계열.
- **포인트 컬러 ① 시그널 레드** `#E03B3B` — 위험·감소·경고 지표, 부정 막대, 핵심 경고 콜아웃 보더. 슬라이드당 1회 이내로 절제.
- **포인트 컬러 ② 시그널 그린** `#1F9D57` — 달성·증가·긍정 지표, 긍정 막대, 완료 표시.
- **정보 박스 틴트 라이트블루** `#E8F1FB` — KRDS 박스 콜아웃(정보·요약) 채움. 표면색.
- 본문 텍스트 `#1A1A1A`, 보조 `#5C6470`, 헤어라인 `#C5D2E3`.
- 색 규칙: 네이비는 구조(헤더·번호), 블루는 강조, 레드/그린은 지표의 방향성(↓위험 / ↑긍정)에만. 무지개 차트·장식용 색칠 금지. baseline의 평면 네이비 단색과 달리 이 팩은 의미가 부여된 4색 시스템이다.

## 타이포그래피
정부보고서식 **장·절 번호 위계**를 타이포로 못박는다 — baseline의 밋밋한 제목 한 줄과 달리 이 팩은 다단 위계가 또렷이 보여야 한다.
- 폰트: `Pretendard` (대체 `Noto Sans KR`, `Malgun Gothic`). 한글 슬라이드 전용.
- **장 번호(헤더바 좌상단)**: "Ⅰ·Ⅱ·Ⅲ" 로마숫자 또는 "01·02·03", 14pt / Bold / 흰색 / 자간 +6%.
- **헤더바 타이틀**: 26pt / Bold(700) / 흰색 / 자간 -2% / 장 번호 우측에 배치.
- **절 번호 + 섹션 헤딩**: "1." "2." 아라비아숫자 + 헤딩 텍스트, 20pt / Bold / 색 `#0B2C5C`. 헤딩 아래 0.04in 두께 `#0B2C5C` 언더라인.
- 본문: 17pt / Regular(400) / 행간 1.5 (한국어 기준) / 슬라이드당 최대 7줄.
- **요약 박스 텍스트**: 16pt / Medium(500) / 색 `#0B2C5C` — 정보 틴트 박스 안.
- 번호 칩 숫자: 16pt / Bold / 흰색 (칩 안).
- 강조 어절: 본문 중 Bold + 색 `#1B66C9`. 방향성 지표(증감)는 ↑`#1F9D57` / ↓`#E03B3B`.
- 캡션·출처: 10pt / Regular / 색 `#5C6470`.

## 레이아웃 / 그리드
모든 값은 13.33×7.5in 캔버스 기준 **절대값**이다 — layout·space 축이 또렷이 차별화되도록 비율을 못박는다.
- **엄격 12열 그리드.** 좌우 여백 각 0.7in, 헤더바 아래 콘텐츠 상단 여백 0.4in, 하단 0.5in.
- **헤더바: 상단 0~0.9in, 정확히 캔버스 높이의 12%** (7.5in × 0.12 = 0.9in). 네이비 `#0B2C5C` 풀폭 채움. 좌측에 장 번호 칩 + 타이틀, 우측에 기관 로고 자리(0.6in 정사각). 이 12% 비율은 모든 본문·차트 슬라이드에서 동일하게 고정.
- **번호 칩 시스템**: 0.45in 정사각, KRDS 블루 `#1B66C9` 채움, 흰 숫자. 본문 섹션마다 좌측에 세로 배열, 칩 간 간격 0.25in. 칩 우측 0.2in 띄우고 텍스트 블록.
- **KRDS 박스 콜아웃 시스템** — 3종 고정:
  - *정보 박스*: `#E8F1FB` 채움 + 좌측 4px `#1B66C9` 보더. 일반 보충 설명.
  - *요약 박스*: `#E8F1FB` 채움 + 상하 0.04in `#0B2C5C` 보더, 좌상단에 "요약" 라벨(11pt Bold 흰 글씨 네이비 칩).
  - *경고 박스*: 흰 채움 + 좌측 4px `#E03B3B` 보더. 위험·유의 사항에만.
- 본문 슬라이드는 좌측 절번호 영역 + 우측 박스 콜아웃 영역의 2분할 구조. 섹션 간 `#C5D2E3` 헤어라인 구분.
- 하단에 페이지 번호(우) + 출처 캡션(좌), 10pt, 본문 영역과 0.04in `#C5D2E3` 헤어라인으로 분리.

## 형태 / 질감
- 모서리 반경 2px (거의 직각, 공식 문서 톤). 그림자 금지.
- 번호 칩: KRDS 블루 `#1B66C9` 채움 정사각(반경 2px). 장 번호 칩만 네이비 `#0B2C5C` 채움. 아이콘은 2px 스트로크 라인 아이콘, 네이비 단색.
- 박스 콜아웃은 위 "레이아웃" 3종 규격을 그대로 따른다 — 좌측 보더 두께 4px 고정, 박스 내부 패딩 0.2in.

## 차트 / 데이터 시각화 (정부보고서식 — 의미색 + 정돈)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). KRDS 의미색 체계를 따라 **색이 방향성을 인코딩**한다 — baseline의 단색 네이비 막대와 차별화하는 핵심.
- **데이터 색(의미색 고정):** 증가·달성·긍정 막대 `#1F9D57`(시그널 그린), 감소·위험·부정 막대 `#E03B3B`(시그널 레드), 중립 주계열 `#1B66C9`(KRDS 블루), 보조 계열 `#9DB4CE`(옅은 청회색). 한 차트가 단일 계열이면 전부 `#1B66C9`, 강조할 막대 1개만 의미색(↑그린/↓레드). 무지개·장식용 색칠 금지.
- **데이터 잉크 최소화:** 차트 테두리 박스 제거, 배경 채움 제거. 격자선은 y축 주요 눈금에 `#E3EAF3` 0.5pt 헤어라인 1~2개만. 범례 박스는 계열 4개 이상일 때만, 그 미만은 직접 레이블링.
- **축:** x축 베이스라인만 `#C5D2E3` 0.75pt 헤어라인. y축선 생략. **막대 기준선 반드시 0에서 시작**(잘린 y축 금지 — 정부 통계 왜곡 금지).
- **값 레이블:** 막대 끝 위/꼭짓점에 직접 표기, **14pt Bold Pretendard**, 색은 막대색과 일치(중립=`#1A1A1A`), 자릿수·단위 일관(예 "12.3%" "1,240억 원"), 탭형 정렬. 카테고리명 막대 아래 12pt `#5C6470`.
- **막대 형태:** 막대 폭 : 간격 = 3 : 2, 모서리 반경 2px(공식 문서 톤). 라인 차트는 1.75pt 실선 `#1B66C9`, 마커는 끝점·강조점만.
- **출처 의무:** 차트 하단 좌측에 10pt `#5C6470` 출처 캡션 + 단위. 데이터를 쓰면 출처는 필수.

## 다이어그램·컴포넌트 (정부보고서식 — 번호 칩 + 헤어라인 키트)
색·분위기만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며(div 블록 금지), **하나의 다이어그램 언어**를 공유한다 — 노드 모서리 반경 2px 고정, 커넥터 1.75pt 직각 화살표(화살촉 6px 삼각, 곡선 금지), 단계/레벨 번호는 0.45in 정사각 칩(KRDS 블루 `#1B66C9` 채움·흰 숫자 16pt Bold), 강조는 의미색(↑`#1F9D57`/↓`#E03B3B`)으로만. 모든 다이어그램에 출처가 데이터에서 왔다면 하단 10pt `#5C6470` 캡션.
- **프로세스 플로우:** 직각 사각 노드(높이 0.85in, 모서리 2px, 흰 채움 + 1px `#C5D2E3` 보더), 노드 좌상단에 0.45in 번호 칩, 노드 사이 1.75pt `#1B66C9` 직각 커넥터 + 6px 삼각 화살촉. 활성/현재 단계 노드만 `#E8F1FB` 채움 + 좌측 4px `#1B66C9` 보더. 가로 4~5단계.
- **타임라인:** 수평 1pt `#C5D2E3` 축선, 마일스톤은 0.18in 정사각 마커(`#1B66C9`), 현재 시점만 `#0B2C5C` 채움 마커 + 위에 "현재" 11pt Bold 네이비 칩 라벨. 날짜 라벨 축 아래 12pt `#5C6470`, 이벤트 라벨 축 위 14pt `#1A1A1A`. 지연·위험 마일스톤은 `#E03B3B` 마커.
- **비교 레이아웃:** 2~3열, 각 열 상단에 네이비 `#0B2C5C` 헤더 띠(높이 0.4in, 흰 16pt Bold 라벨), 열 본문은 `#E8F1FB` 채움 행 / 흰 행 교대. 열 사이 1px `#C5D2E3` 수직 헤어라인. 비교 항목 라벨은 좌측 고정 열에 16pt Medium `#0B2C5C`. 우열 표시는 ↑`#1F9D57`/↓`#E03B3B` 글리프.
- **매트릭스 2×2:** 0.75pt `#C5D2E3` 십자 축, 축 4끝에 12pt `#5C6470` 축 라벨, 사분면 배경 채움 없음(흰 유지). 데이터 포인트는 0.3in 원형 버블(`#1B66C9` 채움·흰 라벨), 핵심 사분면(우상)에 놓인 항목만 `#0B2C5C` 채움. 사분면 제목은 각 칸 좌상단 14pt Bold `#0B2C5C`.
- **계층/퍼널:** 정부 조직도식 — 상하 계층은 직각 사각 노드 + 1.75pt `#1B66C9` 수직 직각 커넥터, 레벨 라벨 좌측에 0.45in 번호 칩(Ⅰ·Ⅱ·Ⅲ 로마숫자 가능). 퍼널은 위→아래로 폭 좁아지는 사다리꼴 4단(직각 모서리), 각 단 `#1B66C9` 명도 단계(연→진), 단 우측에 단계명 + 수치 16pt Bold.
- **KPI·스탯 카드:** 흰 채움 + 1px `#C5D2E3` 보더(모서리 2px), 좌측 4px 보더로 상태 인코딩(긍정 `#1F9D57`/위험 `#E03B3B`/중립 `#1B66C9`). 거대 수치 32pt Bold `#0B2C5C`, 위에 13pt `#5C6470` 라벨, 아래 증감은 ↑`#1F9D57`/↓`#E03B3B` 14pt Bold + 화살표 글리프. 카드 내부 패딩 0.2in.
- **목차/섹션 디바이더:** 목차는 절번호 칩(0.45in `#1B66C9`) + 헤딩 세로 배열, 항목 사이 1px `#C5D2E3` 헤어라인. 디바이더는 상단 1/3 네이비 `#0B2C5C` 블록 + 거대 장 번호(Ⅰ·Ⅱ) 96pt 흰색 + 장 제목 26pt. 인용 슬라이드는 좌측 4px `#1B66C9` 보더 + 20pt Medium `#0B2C5C` 풀쿼트.

## 전환 (PPT)
즉시 컷 또는 0.2s 페이드만. 모핑·날아오기 금지.

## 하지 말 것
- **네이비 단색만으로 슬라이드를 채우기** — baseline의 평면 네이비와 구별이 안 된다. 포인트 컬러(레드/그린)와 정보 틴트(`#E8F1FB`)를 의미에 맞게 반드시 운용한다.
- 헤더바 비율을 12%(0.9in)에서 벗어나기 — 모든 본문·차트 슬라이드에서 정확히 고정.
- 한글 폰트를 Pretendard·Noto Sans KR 외로 — 폰트 깨짐 방지를 위해 반드시 한글 지원 폰트.
- 헤더바·장 번호·절 번호 위계를 생략하기 — 정부보고서식 다단 번호 위계는 필수.
- 레드/그린을 장식용으로 칠하기 — 오직 지표의 방향성(위험↓ / 긍정↑)에만.
- 둥근 카드, 그림자, 그라디언트.
- **아마추어 차트 회귀 금지:** 3D·입체 막대, 막대/조각 그림자, 무지개·장식용 색칠(색은 방향성 인코딩 전용), 격자선 과다(헤어라인 1~2개만), 차트 테두리 박스, 잘린 y축(0에서 시작 안 함), 출처 누락.
- 이모지 불릿·클립아트. 불릿은 KRDS 블루 사각 마커만.
- 본문을 7줄 넘게 채우기. 한국어는 줄당 글자 수가 많으니 줄 수를 엄격히 제한.

## 적용 예
- **표지:** 슬라이드 상단 1/3을 네이비 `#0B2C5C` 단색 블록으로 채우고 그 안에 장 구분 없는 26pt 흰 보고서 제목 + 14pt 부제. 제목 아래 `#1B66C9` 0.06in 두께 짧은 라인 1개. 하단 흰 영역에 발행 기관·날짜 12pt.
- **본문 슬라이드:** 12% 네이비 헤더바(좌상단 장 번호 칩 + 타이틀) + 좌측 번호 칩 3개 세로 배열, 각 칩 옆 KRDS 박스 콜아웃(정보/요약 박스 혼용). 핵심 유의 사항은 경고 박스로. 하단 출처.
- **차트 슬라이드:** 12% 네이비 헤더바 + 좌측 SVG 막대 차트 — 의미색(증가 `#1F9D57`·감소 `#E03B3B`·중립 `#1B66C9`), 막대 폭:간격 3:2, 막대 끝 14pt Bold 값 레이블·12pt 카테고리명, x축 헤어라인·격자선 1~2개·0 기준선. 우측 `#E8F1FB` 요약 박스에 해석 텍스트. 차트 하단 10pt 출처 캡션 + 단위 의무.
