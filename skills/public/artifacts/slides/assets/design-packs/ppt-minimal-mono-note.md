# 미니멀 모노 노트 — ppt 디자인 팩

## 이 스타일의 정체성
극단적 절제. 순백 지면에 모노스페이스 폰트로만 쓰인 텍스트, 색은 잉크 블랙 하나뿐. 장식은 1pt 헤어라인 디바이더 하나로 끝낸다. 모든 텍스트는 좌측 정렬, 정적이고 차분한 "연구 노트" 미감 — 슬라이드라기보다 타이핑한 메모처럼 보인다.

## 색
- 배경: `#FFFFFF`(순백). 다른 배경색·면 채움 금지.
- 텍스트: `#111111`(잉크 블랙).
- 보조 텍스트(캡션·메타): `#8A8A8A`(회색) — 위계 표현용으로만, 면적 최소.
- 강조색 0개. 색으로 강조하지 않고 굵기·크기·여백으로만 위계를 만든다.

## 타이포그래피
- 전 텍스트 단일 패밀리: `JetBrains Mono` (대체: `D2Coding`, `Sarasa Mono K`, monospace) — 한글 모노 대체 폰트 필수.
- 표지 제목: 36pt / Medium. 본문 슬라이드 제목: 28pt / Medium.
- 본문: 22pt / Regular, 행간 1.55. 슬라이드당 8줄 이하.
- 캡션/메타: 14pt / Regular, 회색.
- 자간 0(모노스페이스 기본). 대문자 변형 금지 — 소문자 그대로.
- 불릿은 `-` 하이픈 문자 하나. 도형 불릿·이모지 금지.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 여백 극대화 — 좌우 각 1.4in, 상하 각 1.1in.
- 콘텐츠 폭은 캔버스의 약 60%로 제한, 좌측 정렬. 우측 여백을 일부러 비운다.
- 단일 컬럼만. 2단·다단 레이아웃 금지.
- 슬라이드 번호는 우하단 14pt 회색 `01 / 12` 형식.

## 형태 / 질감
- 디바이더: 1pt 솔리드 검정 수평선. 슬라이드당 최대 1개.
- 보더·박스·카드·그림자 전부 금지. 면을 가두지 않는다.
- 모서리 반경 개념 자체가 없음(박스가 없으므로).
- 이미지: 가급적 사용 안 함. 불가피하면 보더 없는 흑백 그레이스케일 처리, 단일 컬럼 폭 이내.

## 전환 (PPT)
- 전환 없음(None) 또는 즉시 컷. 애니메이션·모션 일절 금지 — 정적인 노트 미감.

## 하지 말 것
- 색·강조색 추가 금지. 보라·파랑 등 어떤 유채색도 금지.
- 박스·카드·보더·그림자·면 채움 금지.
- 산세리프·세리프 폰트 혼입 금지 — 모노스페이스 단일 패밀리만.
- 중앙 정렬 금지(슬라이드 번호 제외). 모든 텍스트 좌측 정렬.
- 다단 레이아웃·아이콘·이모지·일러스트 금지.
- 여백을 콘텐츠로 채우려 하지 말 것 — 빈 우측 여백이 정체성이다.
- **차트 금지사항(아마추어 회귀 차단):** 3D·그림자·입체 막대 금지. 색 채움 금지 — 막대·선은 단색 잉크 또는 윤곽선만. 격자선 금지. 범례 박스 금지. 무지개 색조 금지(색 자체가 0개). 잘린 y축 금지. 데이터 영역 배경 채움·테두리 박스 금지. 막대를 div·표 셀로 그리지 말 것 — SVG 정밀 렌더.

## 차트·데이터 시각화
미니멀 모노 차트 = 헤어라인 단색. 색이 0개이므로 위계는 굵기·채움 유무·여백으로만 만든다. 연구 노트에 손으로 그린 단색 도표 미감.
- **렌더링:** SVG로 정밀하게 그린다. 막대 폭 : 간격 = 3 : 2. 막대 하단은 동일 기준선(값 0)에 정확히 정렬. 잘린 y축 절대 금지.
- **축·격자:** 격자선 완전 제거. x축(기준선)만 1pt 솔리드 `#111111`. y축선 제거. 눈금 라벨 최소 — 0과 최댓값만, 또는 생략하고 값 직접 표기.
- **데이터 표현:** 막대 차트는 채움 없는 1pt `#111111` 윤곽선 막대 + 강조 1개만 `#111111` 솔리드 채움. 선 차트는 1pt `#111111` 솔리드 라인(꼭짓점 도트 없음 또는 1.5pt 작은 점). 면적은 사용하지 않음(채움 금지).
- **값 레이블:** 막대 위·선 꼭짓점 옆에 직접 표기. `JetBrains Mono` 14pt `#111111`, 탭형(tabular) 정렬, 일관된 자릿수·단위. 소문자·기본 자간 유지.
- **직접 레이블링:** 범례 박스 금지. 계열명은 라인 끝에 14pt 모노 텍스트로 직접 붙인다. 항목명은 막대 아래 14pt 모노.
- **캡션:** 차트 제목·출처는 14pt 회색 `#8A8A8A` 모노, 차트 위 또는 아래 좌측 정렬.
- **차트 타입:** 추세=단색 1pt 선 차트(최대 2개 라인, 1개는 솔리드·1개는 점선으로 구분). 비교=윤곽선 막대. 비중은 도넛 대신 1pt 윤곽선 100% 누적 막대 1개 + 구간 분할선 + 값 직접 표기. 도넛·파이 가급적 회피.

## 다이어그램·컴포넌트
미니멀 모노 다이어그램 키트 = 1pt 헤어라인 윤곽 + 모노스페이스 라벨, 면 채움 없음, 색 0개. 위계는 굵기(1pt/1.5pt)·채움 유무·여백으로만 만든다. 노드는 채움 없는 1pt `#111111` 윤곽 사각, 커넥터는 1pt 솔리드 라인 + ASCII 화살촉(`>`). 손으로 그린 연구 노트 도표 미감. 모든 다이어그램이 이 한 언어를 공유하며 차트와 동일한 헤어라인 잉크. 전부 SVG 정밀 렌더, div 블록 금지.
- **공통 다이어그램 언어:** 노드는 모서리 반경 0, 채움 없는 1pt `#111111` 윤곽 사각만(둥근 모서리·면 채움 금지). 강조가 필요한 노드 1개만 1pt `#111111` 윤곽을 1.5pt로 굵게 — 색·채움으로 강조하지 않음. 커넥터는 1pt 솔리드 `#111111` 라인 + 끝에 모노 `>` 글리프. 단계 번호는 배지 도형 없이 `01` `02` 형식 `JetBrains Mono` 14pt 텍스트로 노드 좌상단에. 라벨은 전부 소문자, 기본 자간.
- **프로세스 플로우:** 가로 4~6단계. 각 노드 사각 1.8in×0.8in, 채움 없는 1pt 윤곽. 노드 간격 0.5in, 커넥터는 1pt 라인 + `>`. 노드 위에 `01`~`0n` 모노 14pt. 현재·핵심 단계 1개만 1.5pt 윤곽. 본문 22pt 모노 라벨.
- **타임라인:** 수평. 1pt 솔리드 `#111111` 축선 1개. 마일스톤은 축 위 1.5pt 작은 점(반경 2pt) + 그 위 14pt 모노 날짜·라벨. 현재 시점은 점 위에 짧은 1pt 세로 틱 + `now` 14pt 라벨로만 표시 — 색 강조 없음.
- **비교 레이아웃:** 2열. 열 사이 1pt 수직 헤어라인 디바이더 1개. 각 열 상단에 28pt 모노 헤더, 그 아래 1pt 수평 디바이더. 항목은 `-` 하이픈 불릿 22pt. 박스·면 채움 없음 — 디바이더 라인만으로 구획.
- **매트릭스 2×2:** 두 축은 1pt 솔리드 `#111111` 라인. 사분면 채움 없음(순백 유지). 사분면 라벨은 각 칸 좌상단 14pt 회색 `#8A8A8A` 모노. 데이터 포인트는 채움 없는 1pt 윤곽 작은 원(반경 4pt), 라벨은 점 옆 14pt 모노. 강조 1개만 1.5pt 윤곽.
- **계층/퍼널:** 채움 없는 1pt 윤곽 사각 스택, 위→아래로 폭이 단계적으로 줄어듦(각 단 0.7in 높이). 단 사이 0.2in 간격. 레벨 라벨은 단 안 좌측 정렬 22pt 모노. 정렬은 좌측 기준 — 중앙 정렬 금지.
- **KPI·스탯 카드:** 카드 박스 없음 — 1pt 상단 헤어라인 디바이더로만 구획한 영역. 거대 수치는 `JetBrains Mono` 48pt `#111111`, 그 아래 14pt 회색 라벨, 증감은 `+`/`-` 부호 + 수치 22pt 모노(색 없음). 좌측 정렬, 2~3개를 1pt 디바이더로 나란히.

## 적용 예
- 표지: 순백 배경, 좌상단 1.4in 지점에 36pt 제목, 그 아래 1pt 디바이더, 디바이더 아래 14pt 회색 메타(작성자·날짜).
- 본문: 좌측 정렬 28pt 제목, 한 줄 띄우고 `-` 하이픈 불릿 본문 22pt 최대 8줄. 우측 40% 여백.
- 차트: SVG 단색 차트. 선 차트는 1pt `#111111` 솔리드 라인, 막대는 1pt 윤곽선 + 강조 1개만 솔리드 채움. 막대 폭:간격 = 3:2. 격자선 제거, x축만 1pt `#111111`, 기준선 0. 값 레이블 14pt `JetBrains Mono` 탭형 정렬로 직접 표기. 범례 대신 라인 끝 14pt 텍스트 라벨. 차트 제목·출처는 14pt 회색 모노.
- 프로세스 슬라이드: 가로 5단계 플로우. 채움 없는 1pt 윤곽 사각 노드 1.8in×0.8in, 커넥터 1pt 라인 + `>`. 노드 위 `01`~`05` 모노 14pt. 핵심 단계 1개만 1.5pt 윤곽. 우측 여백 비움.
- 타임라인 슬라이드: 1pt 솔리드 수평 축선 1개, 마일스톤은 반경 2pt 점 + 14pt 모노 날짜. 현재 시점은 1pt 세로 틱 + `now` 라벨. 색 강조 없이 굵기·여백으로만 위계.
