# 스타트업 피치 컬러풀 — ppt 디자인 팩

## 이 스타일의 정체성
밝고 친근한 투자 피치 덱. 밝은 화이트 배경에 채도 높은 4~5색 팔레트, 크고 둥근 키워드 배지(pill)와 둥근 카드. 거대한 숫자 메트릭이 슬라이드를 지배하고, 친근한 산세리프와 굵은 디스플레이가 섞인다 — 한눈에 "에너지 넘치는 스타트업 피치"로 식별된다.

## 색
- 배경: `#FFFFFF`(순백). 섹션 강조 시 라이트 틴트 `#F4F6FF`.
- 텍스트: `#15161B`(잉크 차콜).
- 활기찬 5색 팔레트: `#5B5BFF`(인디고 블루), `#FF5C8A`(코랄 핑크), `#FFB020`(앰버), `#15C39A`(민트 그린), `#9B5BFF`(바이올렛). 한 슬라이드에 2~3색.
- 그라디언트는 금지하되, 배지·카드는 채도 높은 단색 플랫 채움.

## 타이포그래피
- 디스플레이/메트릭 숫자: `Poppins ExtraBold` (대체: `Pretendard ExtraBold`, sans-serif). 거대 메트릭 96pt — 슬라이드 최대 요소. 표지 제목 50pt.
- 헤드라인: `Poppins Bold` 36pt.
- 본문: `Inter` 또는 `Pretendard` Regular 23pt, 행간 1.45. 슬라이드당 6줄 이하.
- 배지/라벨: `Poppins SemiBold` 16pt, 배지 내부.
- 친근한 산세리프 — 세리프·압축 폰트 금지.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 좌우 여백 각 0.85in, 상하 각 0.75in.
- 콘텐츠는 중앙 정렬 기본 — 키 메시지·거대 메트릭을 화면 중앙에.
- 12열 그리드. 카드는 2~3개를 가로로 균등 배치, 카드 간격 0.25in.
- 거대 메트릭 슬라이드: 숫자 1개 + 짧은 라벨 1줄, 나머지는 여백.

## 형태 / 질감
- 배지(pill): 모서리 반경 999pt(완전 알약형), 채도 높은 단색 채움, 흰색 또는 차콜 텍스트.
- 카드: 모서리 반경 24pt, 흰색 또는 라이트 틴트 채움.
- 보더: 카드에 1.5pt 라이트 그레이 `#E5E7F0` 또는 보더리스.
- 그림자: 부드러운 컬러 틴트 그림자 — 블러 24pt, 불투명도 14%, 카드 색 계열. 검정 하드 섀도 금지.
- 아이콘: 단색 라인 또는 채움 아이콘, 팔레트 색. 이모지 금지.

## 전환 (PPT)
- 전환은 Push 또는 Fade, 0.35s. 카드·배지 등장은 Grow/Bounce(스프링) 0.3s — 경쾌하게.

## 하지 말 것
- 그라디언트·메시 그라디언트 금지 — 채도 높은 단색 플랫만.
- 검정 하드 섀도·각진 직각 카드 금지 — 24pt 라운드 카드 + 부드러운 컬러 섀도.
- 무채색만으로 슬라이드를 만들지 말 것 — 매 슬라이드 컬러 2색 이상.
- 거대 메트릭 슬라이드를 텍스트로 채우지 말 것 — 숫자가 주인공.
- 이모지·클립아트·스톡 일러스트 금지. 아이콘은 단색 라인/채움만.
- 세리프·압축 디스플레이 폰트 혼입 금지 — 친근한 산세리프 유지.
- **차트 금지사항(아마추어 회귀 차단):** 3D·입체 막대·원근 파이 금지. 검정 하드 섀도 금지(부드러운 컬러 틴트 섀도만, 차트 막대엔 섀도 없음). 격자선 금지. 범례 박스 금지 — 직접 레이블링만. 5색 팔레트를 한 차트에 무지개로 다 칠하지 말 것 — 비교 차트는 단색 + 강조 1. 잘린 y축 금지. 데이터 영역 테두리 박스 금지. 파이 5조각+·다중 도넛 금지. div·표 셀 막대 금지 — SVG 정밀 렌더.

## 차트·데이터 시각화
스타트업 피치 차트 = 거대 메트릭 우선 + 심플 라운드 막대 + 배지 스타일 값 레이블. 피치 덱의 차트는 복잡한 데이터 도구가 아니라 "한 숫자를 크게, 차트는 그 숫자를 받쳐주는 단순한 보조"다. 컨설팅식 절제(단색 + 강조 1)를 친근한 라운드 톤으로 실행한다.
- **거대 메트릭 우선:** 핵심 수치 1개는 차트로 그리지 말고 96pt `Poppins ExtraBold` 거대 숫자(인디고 `#5B5BFF`) + 23pt 라벨 1줄로 표현 — 이것이 이 팩의 1순위 데이터 표현이다. 차트는 추이·구성을 보여야 할 때만.
- **렌더링:** SVG로 정밀하게 그린다. 막대 폭 : 간격 = 3 : 2, 막대 상단 모서리 반경 10pt(`card_bar_radius`, 친근한 라운드), 하단은 각지게. 막대 하단 기준선은 값 0에 정확히 정렬. 잘린 y축 절대 금지.
- **축·격자:** 격자선 완전 제거. x축(기준선)만 1.5pt 라이트 그레이 `#E5E7F0` 솔리드. y축선 제거. 눈금 라벨 최소(0·최댓값) 또는 생략.
- **데이터 색:** `tokens.json`의 `color.chart`. 비교 막대는 인디고 `#5B5BFF` 단색 + 강조하려는 막대 1개만 코랄 `#FF5C8A` — 나머지를 5색 무지개로 칠하지 않는다. 다계열일 때만 팔레트 색 순환(최대 4색), 그 경우도 채도는 그대로 플랫.
- **값 레이블:** 막대 위에 배지(pill) 안에 직접 표기 — 모서리 반경 999pt 알약 배지, 막대와 같은 색의 라이트 틴트 채움 또는 흰 배지, 안에 `Poppins SemiBold` 16pt 차콜 `#15161B` 수치. 탭형 정렬, 일관된 자릿수·단위. 배지가 이 팩 차트의 시그니처.
- **직접 레이블링:** 범례 박스 금지. 항목명은 막대 아래 `Poppins SemiBold` 16pt로, 계열명은 라인 끝에 직접 붙인다.
- **차트 타입:** 비교=상단 라운드(10pt) 막대(단색 인디고 + 강조 1코랄). 추세=3pt 팔레트 색 라인(둥근 캡) + 꼭짓점 지름 8pt 속찬 원. 비중=도넛(조각 3개 이하, 팔레트 색, 중앙에 핵심 수치 `Poppins ExtraBold` 36pt). 파이 4조각+·다중 도넛 금지.

## 다이어그램·컴포넌트
스타트업 피치 다이어그램 = 둥근 카드 노드 + 알약 배지 + 굵은 라운드 캡 커넥터 + 부드러운 컬러 틴트 섀도. 모든 다이어그램은 24pt 라운드 카드와 999pt 알약을 어휘로 쓰고, 친근한 채도 높은 단색 플랫 채움을 입는다. 한 언어를 공유한다 — 노드는 모서리 반경 24pt 둥근 카드, 커넥터는 3pt 라운드 캡 라인, 번호 배지는 999pt 알약 또는 정원, 강조는 코랄 `#FF5C8A`. 전부 SVG 정밀 렌더, div 블록 금지.
- **공통 다이어그램 언어:** 노드 = 모서리 반경 24pt 둥근 카드, 흰색/라이트 틴트 채움 + 1.5pt 라이트 그레이 `#E5E7F0` 보더 또는 보더리스 + 부드러운 컬러 틴트 섀도(블러 24pt, 불투명도 14%, 카드 색 계열). 커넥터 = 3pt 라운드 캡 팔레트 색 라인, 화살촉은 둥근 삼각형. 번호 배지 = 지름 0.44in 정원 또는 999pt 알약, 팔레트 색 채움 + 흰색 `Poppins SemiBold` 16pt. 활성/강조 노드만 코랄 `#FF5C8A`.
- **프로세스 플로우:** 4~5단계, 둥근 카드 노드 폭 2.4in × 높이 1.0in(반경 24pt), 흰색 채움 + 컬러 틴트 섀도. 노드 간격 0.4in을 3pt 라운드 캡 인디고 라인 + 둥근 삼각형 화살촉으로 연결. 노드 좌상단에 정원 번호 배지(팔레트 색 순환), 내부 `heading` 축약 + 16pt 라벨. 활성 단계 1개만 코랄 `#FF5C8A` 채움(흰색 텍스트). 단계 위에 작은 알약 배지로 단계명 표기 가능.
- **타임라인:** 수평 축 = 3pt 라운드 캡 라이트 그레이 `#E5E7F0` 라인. 마일스톤 마커 = 축 위 지름 0.32in 팔레트 색 채운 원, 마커 위에 999pt 알약 배지(날짜) + 23pt 헤드라인. 현재 시점만 코랄 `#FF5C8A` 정원 + 외곽 코랄 링(불투명 14%). 마커 간격 날짜 비례. 미래 구간 마커는 흰 채움 + 1.5pt 그레이 보더.
- **비교 레이아웃:** 2~3개 둥근 카드 가로 균등 배치(12열 6+6 또는 4+4+4), 카드 간격 0.25in, 각 카드 흰색 + 다른 팔레트 색 상단 액센트 바(높이 0.12in). 카드 상단 `heading` 36pt + 그 아래 23pt 본문, 항목 앞 팔레트 색 둥근 점. 추천 카드 1개만 라이트 틴트 채움 + 상단에 코랄 알약 배지("추천"). vs 표기는 카드 사이 지름 0.7in 코랄 정원에 흰색 "VS".
- **매트릭스 2×2:** 사분면 = 4개 둥근 카드를 0.25in 간격으로 2×2 배치(각 한 변 3.0in, 반경 24pt), 흰색 채움 + 라이트 틴트 좌상단 모서리 액센트. 축 라벨 = 매트릭스 바깥 상하·좌우에 `label` 16pt. 데이터 포인트 = 지름 0.5in 팔레트 색 채운 원(버블, 값 따라 0.35~0.75in 가변) + 안에 또는 옆에 16pt 라벨, 핵심 포인트 1개만 코랄 `#FF5C8A`.
- **계층/퍼널:** 수직 적층 둥근 카드 단, 각 높이 1.0in(반경 24pt), 폭은 계층=위→아래·퍼널=아래로 축소(폭 차이 1.5in씩), 단 간격 0.15in. 각 단 팔레트 색 순환 단색 채움(흰색 텍스트), 좌측 정원 번호 배지, 내부 `heading` 축약 + 16pt 라벨. 퍼널은 각 단 우측에 전환율 % 알약 배지. 정점/병목 단 1개만 코랄.
- **KPI·스탯 카드:** 카드 = 모서리 반경 24pt 둥근 카드, 흰색/라이트 틴트 채움 + 컬러 틴트 섀도. 거대 수치 `metric` 96pt(인디고 `#5B5BFF`, 핵심 1개만 코랄) — 카드 안 최대 요소. 그 위 16pt 라벨, 아래 증감 알약 배지(상승=민트 `#15C39A` 틴트, 하락=코랄 `#FF5C8A` 틴트, 둥근 삼각형 + 수치). 카드 3개는 12열 4+4+4 균등, 간격 0.25in.

## 적용 예
- 표지: 순백 배경, 중앙에 50pt Poppins ExtraBold 제목, 그 아래 인디고·코랄 알약 배지 2개, 하단 16pt 라벨. 우상단에 민트 정원 장식.
- 본문: 중앙 36pt 헤드라인 + 23pt 본문, 그 아래 가로로 둥근 카드 3개(각기 다른 팔레트 색 아이콘 + 짧은 텍스트).
- 메트릭 슬라이드: 화면 중앙에 96pt 거대 숫자(인디고), 바로 아래 23pt 라벨 1줄, 좌우 광활한 여백.
- 다이어그램(프로세스): SVG 4단계 플로우. 둥근 카드 노드(2.4×1.0in, 반경 24pt) 흰색 + 컬러 틴트 섀도, 3pt 라운드 캡 인디고 라인 + 둥근 삼각형 화살촉 연결. 좌상단 정원 번호 배지, 활성 단계 1개만 코랄 `#FF5C8A`.
- 다이어그램(퍼널): SVG 4단 수직 퍼널. 둥근 카드 단(높이 1.0in, 반경 24pt) 팔레트 색 순환 채움, 폭 1.5in씩 축소, 우측에 전환율 % 알약 배지. 병목 단 1개만 코랄.
- 차트: SVG 라운드 막대 차트. 막대 폭:간격 = 3:2, 상단 모서리 10pt 라운드. 막대는 인디고 `#5B5BFF` 단색 + 강조 막대 1개만 코랄 `#FF5C8A`. 격자선·범례 제거, x축만 1.5pt `#E5E7F0`, 기준선 0. 값 레이블은 막대 위 알약 배지 안에 `Poppins SemiBold` 16pt로 직접 표기, 항목명은 막대 아래 16pt. 단일 핵심 수치면 차트 대신 96pt 거대 메트릭.
