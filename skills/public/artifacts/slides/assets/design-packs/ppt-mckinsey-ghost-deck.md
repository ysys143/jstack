# MBB Ghost Deck Framework — ppt 디자인 팩

## 이 스타일의 정체성
순백 캔버스, 상단을 완결된 문장의 **액션 타이틀** 한 줄이 차지하고 그 아래 작은 키커 라인이 붙는다. 본문은 무채색 슬레이트 그레이 단 한 톤 — 강조는 색이 아니라 굵기와 박스 채움 한 칸으로만 한다. 우하단 출처 각주는 의무. 워터폴·메코(marimekko)·2×2 매트릭스가 기본 다이어그램 어휘다. "예쁜 슬라이드"가 아니라 "스스로 결론을 말하는 슬라이드"임을 액션 타이틀과 무채색 다이어그램 키트로 즉시 알 수 있다.

## 색
- 배경 `#FFFFFF` 순백 (전 슬라이드 동일).
- 텍스트/데이터 무채색 단계만:
  - 잉크 `#1A1A1A` — 액션 타이틀.
  - 슬레이트 `#3D4350` — 본문.
  - 미드 그레이 `#7A828F` — 키커·캡션·보조 데이터.
  - 라이트 그레이 `#C9CDD3` — 비강조 막대·헤어라인.
- 강조색은 단 1색 — 잉크 네이비 `#1F3A5F`. 차트의 강조 막대 1개·박스 채움 1칸·델타 표식에만. 텍스트 강조는 색이 아니라 Bold.
- 워터폴 감소 막대 빗금 패턴은 `#7A828F` 위 45° 0.75pt 헤어라인.

## 타이포그래피
- 폰트: 라틴 **Inter**, 한글 **Pretendard** (대체 `Arial`, `Noto Sans KR`). 공개 폰트.
- 액션 타이틀 26pt / Semibold / 자간 -0.01em / 행간 1.25 / 최대 2줄, 완결된 평서문.
- 키커 라인 13pt / Medium / 자간 0.04em / 대문자 / `#7A828F`.
- 본문 18pt / Regular / 행간 1.35 / 슬라이드당 6줄 이하.
- 다이어그램 라벨 14pt / Medium.
- 차트·KPI 수치 라벨 14pt / Semibold / tabular figures.
- 출처 각주 10pt / Regular / `#7A828F`.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 좌우 여백 각 0.6in, 상단 여백 0.5in, 하단 여백 0.4in. 12열 그리드.
- **액션 타이틀 밴드**: 상단 0~1.3in, 좌측 정렬. 그 아래 0.08pt가 아닌 0.75pt `#C9CDD3` 룰 라인 1줄.
- 본문/다이어그램 영역: 1.5~6.9in. 비대칭 배치 — 다이어그램은 우측 2/3, 설명 텍스트는 좌측 1/3 같은 빽빽한 컨설팅 배치.
- 출처 각주: 우하단 6.95in, 10pt, 의무. "출처: …" + 단위 명기.
- 슬라이드 번호: 좌하단 10pt.

## 형태 / 질감
- 모든 도형 모서리 반경 0px — 직각만.
- 보더 0.75~1pt `#C9CDD3` 헤어라인. 채움 강조는 잉크 네이비 1칸.
- 그림자·그라디언트·아이콘 장식 없음.
- 화살표는 1pt 셰브론(삼각 화살촉, 채움).

## 전환 (PPT)
- 전환 없음(`none`). 컷 전환. 액션 타이틀의 정적 권위가 정체성 — 모션을 쓰지 않는다.

## 차트·데이터 시각화
컨설팅 차트의 핵심: 데이터 잉크 최소화 + 강조 1개 + 직접 라벨링 + 출처 각주.
- **워터폴 차트.** 시작·끝 막대는 잉크 네이비 솔리드, 증가 막대는 `#3D4350` 솔리드, 감소 막대는 `#7A828F` 위 45° 빗금. 막대 사이 0.5pt `#C9CDD3` 점선 커넥터. 막대 폭 0.7in, 간격 0.25in. 각 막대 위 14pt Semibold 값 라벨 + 증감 부호.
- **메코(marimekko / 가변폭 100% 누적).** 열 폭 = 한 변수(예 시장규모), 세로 분할 = 비중. 열은 무채색 명도 단계, 강조 세그먼트 1칸만 잉크 네이비. 각 세그먼트 안 14pt 퍼센트 라벨.
- **100% 누적 막대.** 세그먼트 무채색 명도, 강조 1칸 잉크 네이비, 세그먼트 안 직접 라벨.
- **일반 비교 막대.** 강조 막대 1개만 잉크 네이비, 나머지 `#C9CDD3`. 막대:간격 = 3:2. 격자선 제거, x축 베이스라인 0.75pt만, y축 생략. 막대 위 14pt 값 직접 표기, tabular.
- **금지.** 무지개색·범례 박스·3D·도넛 다중·잘린 y축. 범례 대신 직접 라벨링. 기준선은 항상 0.
- 모든 차트 SVG 정밀 렌더 — div 블록 막대 금지. 우하단 출처 각주 의무.

## 다이어그램·컴포넌트
모든 다이어그램은 0radius 직각 도형·무채색·1pt 셰브론·사각 번호 배지라는 한 언어를 공유한다. 강조는 색이 아니라 잉크 네이비 채움 1칸 또는 Bold.
- **프로세스 플로우.** 0radius 직사각 노드(높이 0.8in, 1pt `#C9CDD3` 보더, 흰 채움). 노드 사이 1pt 셰브론 화살표(`#3D4350`). 단계 번호는 노드 좌상단 사각 배지(0.32in 정사각, 잉크 네이비 채움, 흰 숫자 14pt Semibold). 활성 단계 노드만 잉크 네이비 좌측 3pt 바.
- **타임라인.** 수평 베이스라인 0.75pt `#3D4350`. 마일스톤은 다이아몬드 마커(0.18in, 무채색, 현재만 잉크 네이비 채움). 페이즈 구간은 베이스라인 위 헤어라인 괄호 + 14pt 페이즈 라벨. 날짜 10pt 아래, 이벤트 14pt 위.
- **비교 레이아웃.** 2~3열 표. 헤더 행만 슬레이트 `#3D4350` 채움 + 흰 글자. 셀 구분 0.75pt `#C9CDD3` 헤어라인. 충족=체크 글리프, 미충족=대시 글리프(둘 다 무채색, 단 우월 항목 열 헤더는 잉크 네이비).
- **매트릭스 / 2×2.** BCG형. 채움 없는 헤어라인 십자축(0.75pt `#C9CDD3`). 4개 사분면 라벨은 모서리 14pt. 데이터는 라벨 버블 — 원 지름 = 3번째 변수, 채움은 무채색(강조 항목만 잉크 네이비), 버블 안/옆 14pt 라벨.
- **계층 / 피라미드.** 미니토 피라미드 원칙 트리 — 최상단 결론 박스 1개, 아래로 근거 박스 2~3개씩 분기, 1pt 직각 꺾임 커넥터. 또는 3~4단 피라미드(직각 사다리꼴, 무채색 명도 단계).
- **KPI·스탯 카드.** 무테 카드(보더 없음, 흰 배경). 거대 수치 40pt Bold `#1A1A1A` + 14pt 라벨 + ▲▼ 델타 — 델타는 색 없이 굵기와 삼각 글리프로만(상승 ▲ Bold, 하락 ▽ Regular). 슬라이드당 3~4개, 세로 0.75pt 헤어라인으로 구분.
- **목차 / 섹션 디바이더 / 인용.** 목차는 좌측 번호(01~) + 슬레이트 항목 리스트. 디바이더는 좌측에 거대 60pt 섹션 번호 + 우측 액션 타이틀형 섹션 문장. 인용 슬라이드는 풀쿼트 24pt Regular 슬레이트 + 좌측 잉크 네이비 3pt 바.
- 모든 다이어그램 SVG 정밀 렌더 — div 블록 금지.

## 하지 말 것
- 액션 타이틀을 명사구·제목어로 쓰지 말 것 — 반드시 완결된 평서문("매출은 신흥시장에서 성장한다") 한 줄.
- 색으로 강조하지 말 것 — 강조색은 1색, 차트 막대 1개·박스 1칸·델타에만. 텍스트 강조는 Bold.
- 무지개 차트·범례 박스 남발·격자선·3D 효과·둥근 모서리·그림자·그라디언트 금지.
- 클라이언트 실명·MBB(맥킨지·BCG·베인) 회사 로고·실제 컨설팅사 슬라이드 복제 금지. 일반화된 프레임워크만.
- 출처 각주 누락 금지 — 모든 데이터 슬라이드 우하단 의무.
- 이모지·클립아트·스톡 아이콘 금지. 슬라이드를 글로 가득 채우기 금지.
- 모든 슬라이드 중앙 정렬 금지 — 액션 타이틀·본문 좌측 정렬, 다이어그램은 비대칭.

## 적용 예
- **표지.** 순백 캔버스, 좌측 정렬 큰 제목(완결 문장형) + 키커 라인 + 하단 발표사·날짜. 우하단 출처/기밀 표기.
- **본문(스테이트먼트).** 상단 액션 타이틀 + 룰 라인. 좌측 1/3 본문 4줄, 우측 2/3에 보조 다이어그램(프로세스 또는 피라미드 1개).
- **워터폴 차트 슬라이드.** 액션 타이틀 "원가 절감의 70%는 물류에서 나온다". 워터폴 막대 7개 — 시작/끝 잉크 네이비, 감소 막대 빗금, 각 막대 위 값+부호, 우하단 출처 각주.
- **메코 차트 슬라이드.** 액션 타이틀 한 줄. 가변폭 100% 누적 열 5개(폭=시장규모), 강조 세그먼트 1칸 잉크 네이비, 세그먼트 안 퍼센트 라벨, 출처 각주.
- **2×2 매트릭스 슬라이드.** 액션 타이틀. 헤어라인 십자축 + 4사분면 라벨, 데이터 버블 6개(크기=매출), 강조 버블 1개 잉크 네이비, 좌측 1/3 해설 텍스트.
- **프로세스 다이어그램 슬라이드.** 직사각 노드 5개 + 셰브론 화살표, 좌상단 사각 번호 배지 01~05, 활성 노드 좌측 잉크 네이비 바, 노드 아래 14pt 캡션.
- **KPI 슬라이드.** 무테 카드 4개 — "EBITDA 마진 18%", "신규 고객 +2.4K" 등, 거대 수치 + ▲▼ 델타, 세로 헤어라인 구분, 우하단 출처 각주.
