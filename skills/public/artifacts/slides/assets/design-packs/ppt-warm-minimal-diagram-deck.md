# 웜 미니멀 다이어그램 — ppt 디자인 팩

아래 지시를 한 블록으로 따라 16:9(13.33×7.5in) 슬라이드 덱을 만든다. 웜 미니멀 다이어그램 — 따뜻한 샌드-아이보리 캔버스에 잉크 브라운 본문, 단일 테라코타 강조, 가는 1pt 라인 다이어그램과 넉넉한 여백의 절제된 따뜻한 미니멀 다이어그램 키트.

## 이 스타일의 정체성
한눈에 알아보는 단서: (1) 모든 다이어그램 도형이 채움보다 가는 1pt 윤곽선 + 라운드 코너로 그려진다, (2) 따뜻한 샌드-아이보리 배경 + 잉크 브라운 텍스트 + 테라코타 강조 단 한 점, (3) 넉넉한 여백 — 슬라이드의 절반 이상이 빈 공간. 부드럽고 절제됐지만 또렷한 라인 다이어그램.

## 색
- 배경 `#F2EBDF` (따뜻한 샌드-아이보리)
- 카드/노드 표면 `#FBF7EF` (밝은 아이보리, 거의 배경과 동일)
- 본문 잉크 `#3D3528` (잉크 브라운), 보조 `#8A8170`
- 테라코타 강조 `#C2693F` — 단 하나의 강조색, 강조 1요소·강조 1막대에만
- 라인·헤어라인 `#3D3528` (다이어그램 윤곽선), 옅은 룰 `#D6CCB8`
- 강조색은 테라코타 1색뿐. 2번째 강조색·그라디언트·발광 금지.

## 타이포그래피
- 폰트: `Work Sans`(휴머니스트 산세리프, 디스플레이·본문, 대체 `Arial`). 한글은 `Pretendard`.
- 슬라이드 타이틀: 30pt / Work Sans 500 / 자간 -1%
- 키커/오버라인: 12pt / Work Sans 600 / 자간 +8% / 대문자 / 색 테라코타
- KPI 대형 수치: 52pt / Work Sans 300(라이트) / 잉크 브라운
- 노드 번호: 16pt / Work Sans 500 / 떠 있는 테라코타 원 배지 안(흰 숫자)
- 본문: 18pt / Work Sans 400 / 행간 1.5 / 슬라이드당 5줄 이하
- 캡션·축 레이블: 11pt / Work Sans 500 / 색 `#8A8170`

## 레이아웃 / 그리드
- **센터드(airy).** 좌우 여백 각 1.0in, 상하 0.8in — 넉넉한 여백이 정체성. 12열 그리드.
- 콘텐츠는 슬라이드 중앙축 기준 정렬(단, 본문 슬라이드는 단조로움 회피 위해 좌우 비대칭 1회 허용).
- 한 슬라이드 핵심 메시지 1개. 다이어그램/노드 모듈 2~4개만 — 적게, 크게, 여백 넉넉히.
- 슬라이드 하단에 가는 1pt `#D6CCB8` 룰 + 11pt 캡션(쪽 번호·섹션).

## 형태 / 질감
- 모서리 반경 10~14px(부드러운 라운드, 통통하지 않게).
- 도형은 **채움보다 윤곽선** — 무채움 + 1pt `#3D3528` 보더가 기본. 강조 요소만 테라코타 채움 또는 테라코타 보더.
- 그림자 거의 없음(허용 시 `0 2px 8px` 검정 5% 아주 옅게). 그라디언트·베벨·발광 금지.
- 아이콘: 1.5pt 스트로크 가는 라인 아이콘 단색(잉크 브라운, 강조는 테라코타), 둥근 끝.

## 차트·데이터 시각화 (헤어라인 라인 차트 — 가늘고 절제되게)
차트는 SVG로 정밀 렌더한다(div 블록 막대 금지). 가는 라인 미감 — 데이터도 윤곽선 위주, 강조 1점만 테라코타.
- **데이터 색:** 강조색 없음이 기본. 막대는 무채움 윤곽(1pt `#3D3528` 보더). 강조할 막대 **1개만** 테라코타 `#C2693F` 솔리드 채움. 라인은 1pt 잉크 브라운 헤어라인, 강조 라인만 테라코타. 다계열은 잉크 브라운 + 테라코타 2색까지(그 이상 금지). 무지개·다색 채색 금지.
- **막대 형태:** 막대 폭 : 간격 = 2 : 3(가는 막대, 여백 넉넉). 모서리 반경 0~2px. 베이스라인 0에서 정확히(잘린 y축 금지).
- **데이터 잉크 최소화:** 격자선 거의 없음(y축 최댓값 1개만 0.5pt `#D6CCB8` 헤어라인 권장). 차트 테두리 박스·배경 채움 제거. x축 베이스라인만 0.75pt `#3D3528`.
- **값 레이블:** 막대 끝/꼭짓점에 직접 표기. `Work Sans` 13pt 500, 색 잉크 브라운(강조는 테라코타), 탭형 정렬, 단위·자릿수 일관. 카테고리명 막대 아래 11pt `#8A8170`. 범례 박스 금지 — 계열명 차트 옆 11pt 라벨 + 가는 색 선 견본.
- **차트 타입 매칭:** 비교=가는 윤곽 막대(강조 1개 테라코타 채움), 추세=1pt 헤어라인 라인 차트(속 빈 원 마커, 면적 채움 없음 또는 테라코타 8% 아주 옅게), 비중=도넛(가는 아크, 조각 3개 이하, 중앙 핵심 수치 28pt 라이트 + 라벨 11pt). 파이·3D·다중 도넛 금지.
- **출처:** 차트 하단 좌측 11pt Work Sans `#8A8170` 출처·단위 캡션 의무.

## 다이어그램·컴포넌트 (가는 라인 윤곽선 다이어그램 키트)
색만으로는 템플릿이 아니다. 아래 컴포넌트를 모두 SVG로 정밀 렌더하며(div 블록 금지) **하나의 다이어그램 언어**를 공유한다 — 모든 노드/카드는 라운드 코너(반경 10~14px) 무채움 + 1pt `#3D3528` 윤곽선, 커넥터는 1pt 곡선 선 + 가는 화살촉, 단계 번호는 떠 있는 테라코타 풀라운드 원 배지(흰 숫자 16pt), 강조는 단 1요소만 테라코타 채움 또는 테라코타 보더.
- **프로세스 플로우:** 가로 3~5단계, 각 노드 = 라운드 코너 사각(높이 0.95in, 무채움 + 1pt 잉크 브라운 보더), 노드 사이 1pt 곡선 커넥터(부드러운 베지어 곡선, 끝 가는 삼각 화살촉). 단계 번호는 노드 좌상단에 떠 있는 테라코타 원 배지(0.42in, 흰 숫자). 활성 단계만 테라코타 1pt 보더 + 옅은 테라코타 8% 채움.
- **타임라인:** 가는 수평선(1pt `#3D3528`), 마일스톤은 속 빈 원 마커(0.2in, 1pt 보더 무채움), 현재 시점만 테라코타 솔리드 채움 원. 라벨은 상하 교대 배치(위/아래 번갈아) — 날짜 11pt `#8A8170`, 이벤트명 16pt.
- **비교 레이아웃:** 2~3열, 1pt 헤어라인 룰로 열 구획. 각 열 상단 12pt 테라코타 소형 대문자 헤더, 행은 항목 + 라인 체크 아이콘(1.5pt 가는 라인). 우세 항목만 테라코타 텍스트·테라코타 라인 아이콘.
- **매트릭스 2×2:** 1pt `#3D3528` 십자 축(채움 없는 사분면), 4축 끝 11pt 500 라벨. 데이터 포인트는 속 빈 원(0.24~0.44in, 1pt 보더 무채움, 크기=세 번째 변수), 강조 포인트만 테라코타 솔리드 채움 + 옆 11pt 라벨.
- **계층/퍼널:** 가는 윤곽선 적층 사다리꼴 — 위→아래 폭 좁아지는 4~5단(무채움 + 1pt 잉크 브라운 보더, 단 사이 0.1in 간격), 각 단 우측에 가는 라인 리더 + 16pt 단계명 + 52pt 라이트 수치. 강조 단만 테라코타 보더.
- **KPI·스탯 카드:** 1pt 보더 라운드 카드(무채움 또는 아이보리 채움, 반경 12px), 좌상단 1.5pt 가는 라인 아이콘 + 12pt 테라코타 키커, 거대 52pt Work Sans 300 라이트 잉크 브라운 KPI 수치, 옆에 13pt 델타(테라코타 라인 화살표 ↑/↓ — 색은 테라코타 단색, 방향으로 구별), 우하단 가는 도넛 진행 링(1pt 테라코타 아크, 트랙 `#D6CCB8`).
- **목차/섹션 디바이더/인용:** 목차는 떠 있는 테라코타 원 번호 배지 + 18pt 항목명 좌측 정렬 리스트 + 가는 1pt 룰 구획. 디바이더는 샌드 배경 + 중앙 12pt 테라코타 키커 + 거대 44pt 섹션명 + 그 아래 가는 1pt 룰. 인용은 좌측 떠 있는 큰 테라코타 윤곽 따옴표 + 26pt Work Sans 라이트 풀쿼트 + 넉넉한 여백.

## 전환 (PPT)
전환 없음 또는 0.3s 아주 옅은 페이드. 빌드 애니메이션 금지 — 절제가 정체성.

## 하지 말 것
- 도형을 솔리드로 채우기 — 채움보다 1pt 윤곽선이 기본, 채움은 강조 1요소만 테라코타.
- 2번째 강조색 추가 — 테라코타 단 1색. 무지개·다색 차트 금지.
- 그라디언트·발광·베벨·강한 그림자.
- 슬라이드를 글로·도형으로 가득 채우기 — 여백이 절반 이상, 모듈 2~4개만.
- 굵은 보더(1.5pt 초과), 통통한 큰 라운드(반경 14px 초과).
- 풀블리드 사진 배경(이건 warm-hospitality-deck — 이 팩은 라인 다이어그램 키트가 정체성).
- 이모지 불릿·클립아트·스톡 아이콘, 빌드 애니메이션.
- 차트 회귀: 3D 차트, 다색 채색, 격자선 과다, 범례 박스, 잘린 y축, 파이/다중 도넛.

## 적용 예
- **표지:** 샌드 배경, 중앙 좌측 정렬 30pt 타이틀 + 12pt 테라코타 키커, 우측에 가는 1pt 라인 다이어그램 한 점(노드 3개), 하단 가는 룰 + 11pt 메타. 슬라이드 절반 이상 여백.
- **본문 슬라이드:** 좌측 18pt 본문 4줄 + 12pt 키커, 우측에 4단계 가는 라인 프로세스 플로우(무채움 노드 + 곡선 커넥터 + 테라코타 원 번호 배지) — 비대칭.
- **차트 슬라이드:** 좌측 큰 1pt 헤어라인 라인 차트(속 빈 원 마커·강조 라인만 테라코타·13pt 값 라벨·격자선 거의 없음), 우측 가는 윤곽 막대(강조 1개 테라코타 채움) + 11pt 출처.
- **타임라인 슬라이드:** 가는 수평선 + 속 빈 원 마커 5개(현재만 테라코타 솔리드), 라벨 상하 교대.
- **매트릭스 슬라이드:** 1pt 십자 축(채움 없음), 속 빈 원 데이터 포인트 5개(강조 1개만 테라코타 솔리드, 크기=값), 4축 끝 11pt 라벨.
- **KPI 슬라이드:** 1pt 보더 라운드 카드 3~4개 — 각 가는 라인 아이콘 + 52pt 라이트 수치 + 테라코타 라인 화살표 델타 + 가는 도넛 진행 링.
