# Editorial Infographic Deck — ppt 디자인 팩

## 이 스타일의 정체성
오프화이트 지면 위 큰 세리프 헤드라인 + 산세리프 캡션의 잡지 인포그래픽 미감이다. 데이터를 데이터 저널리즘처럼 "읽히는 그래픽"으로 조판한다 — 가는 룰 라인이 지면을 구획하고, 데이터는 잉크빛 단색, 캡션·각주는 세리프, 큰 수치는 본문 활자처럼 짜인다. 강조색은 잉크 레드 한 점뿐. NYT·이코노미스트 그래픽 페이지를 슬라이드로 옮긴 듯한 인쇄물 감각이 표식이다.

## 색
- 배경 `#F6F3EC` 오프화이트(따뜻한 종이빛).
- 본문 텍스트 잉크 `#1C1A17`, 보조 텍스트 `#6B655B`.
- 데이터 단색 잉크 `#33302A` (인포그래픽 데이터 기본색).
- 룰 라인 `#C8C2B4` (헤어라인 0.5~0.75pt).
- 강조색은 잉크 레드 `#B22B1F` **1색** — 차트 강조 막대 1개·핵심 수치 1개·드롭캡 1개에만. 절대 면 채움이나 배경에 쓰지 않는다.

## 타이포그래피
- 폰트: 헤드라인 **Source Serif 4** 또는 **Spectral** (세리프, 공개 폰트). 본문/캡션 **Inter** (산세리프). 한글 헤드라인 **Noto Serif KR**, 한글 본문 **Pretendard** (공개 폰트). 대체 `Georgia`, `Arial`.
- 표지·섹션 헤드라인 44pt / Source Serif 4 Semibold / 자간 -0.01em / 행간 1.12.
- 슬라이드 헤드라인 30pt / Source Serif 4 Semibold.
- 본문 18pt / Inter Regular / 행간 1.4 / 슬라이드당 7줄 이하.
- 캡션·소형 대문자 헤더 11pt / Inter Medium / 자간 0.08em / 대문자 / `#6B655B`.
- 거대 데이터 수치 — 본문 활자처럼 조판: 54pt / Source Serif 4 Semibold (세리프 수치).
- 차트 값 라벨 13pt / Inter Semibold / tabular.
- 출처 각주 10pt / Source Serif 4 Italic / `#6B655B`.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 좌우 여백 각 0.65in, 상하 여백 각 0.5in.
- 12열 그리드. 잡지처럼 2~3단 칼럼 + 가는 룰 라인 구획.
- 슬라이드 상단에 헤드라인 + 그 아래 0.75pt `#C8C2B4` 룰 라인 1줄(섹션 룰).
- 헤드라인 위에 11pt 대문자 키커("그래픽 ⟋ 데이터" 같은 잡지 섹션 라벨).
- 페이지 하단에 출처 각주 룰 라인 + 세리프 이탤릭 각주.

## 형태 / 질감
- 도형은 룰 라인 구획 중심 — 박스 채움 최소, 헤어라인 룰로 구분.
- 모서리 반경 0px. 그림자·그라디언트 없음.
- 드롭캡: 본문 첫 글자를 헤드라인 크기 세리프로(3줄 높이), 잉크 또는 잉크 레드.
- 화살표는 가는 1pt 세리프 감성 선 + 작은 삼각 화살촉.

## 전환 (PPT)
- 전환 없음(`none`). 인쇄물 페이지 넘기듯 컷 전환.

## 차트·데이터 시각화
신문·잡지 데이터 그래픽 미감 — 잉크 단색, 격자 제거, 세리프 캡션, 출처 의무.
- **막대 차트.** 잉크 단색 막대 `#33302A`. 강조 막대 **1개만** 잉크 레드 `#B22B1F`, 나머지 잉크. 막대:간격 = 3:2. 격자선 제거(또는 y축 주요 눈금 1~2개만 0.5pt 헤어라인). 차트 테두리 박스·배경 없음. x 베이스라인 0.5pt `#C8C2B4`.
- **라인 차트.** 1pt 잉크 폴리라인, 면적 채움 없음(또는 옅은 잉크 8% 면적). 강조 구간만 잉크 레드 선. 꼭짓점 값은 13pt 직접 라벨.
- **값 레이블.** Inter Semibold 13pt, tabular, 막대·꼭짓점 위 직접 표기. 거대 수치(헤드라인급)는 Source Serif 4 54pt로 본문 활자처럼.
- **비중.** 도넛(조각 3개 이하, 중앙에 세리프 핵심 수치) 또는 100% 누적 막대 1개. 무지개 금지.
- **금지.** 무지개색·범례 박스·3D·격자선 과다.
- 모든 차트 SVG 정밀 렌더 — div 블록 금지. 차트마다 하단 세리프 이탤릭 출처 각주 의무.

## 다이어그램·컴포넌트
모든 다이어그램은 세리프 번호·가는 룰 라인 구획·잉크 단색·잉크 레드 1점이라는 한 언어를 공유한다. 커넥터 도형보다 룰 라인과 번호 위계로 흐름을 만든다.
- **프로세스 플로우.** 드롭캡 크기 세리프 번호(36pt Source Serif 4, 잉크 또는 잉크 레드)가 각 단계를 연다. 단계는 세로 0.75pt `#C8C2B4` 룰 라인으로 구획 — 화살표 커넥터 대신 룰과 번호 위계가 순서를 만든다. 각 단계 옆 13pt 세리프 캡션.
- **타임라인.** 수평 0.75pt 룰 라인 베이스. 큰 세리프 연도(28pt Source Serif 4)가 룰 위, 수직 0.5pt 틱이 사건 위치. 현재 시점 연도만 잉크 레드. 사건 라벨은 틱 아래 13pt.
- **비교 레이아웃.** 다단 칼럼(2~3) + 칼럼 사이 0.75pt 헤어라인 룰. 각 칼럼 헤더는 11pt 세리프 소형 대문자. 우월 항목 헤더만 잉크 레드. 항목 행은 룰 라인으로 구분.
- **매트릭스 / 2×2.** 표 형식 — 2×2 셀을 0.75pt 룰 라인 격자로 그린다(채움 없음). 데이터 포인트는 잉크 레드 점(지름 0.12~0.3in = 3변수). 사분면 라벨은 셀 모서리 11pt 세리프 대문자.
- **계층 / 비중.** 적층 가로 띠 — 각 띠 폭이 비중에 비례, 띠 사이 0.5pt 룰. 잉크 단색 명도 단계, 강조 띠 1개 잉크 레드. 띠 안 세리프 라벨.
- **KPI·스탯 카드.** 룰 라인으로 구획한 칸(박스 채움 없음). 거대 세리프 수치 54pt + 11pt 대문자 캡션 + 세리프 이탤릭 출처 각주. 슬라이드당 3~4 칸, 칸 사이 0.75pt 세로 룰.
- **목차 / 섹션 디바이더 / 인용.** 목차는 잡지 차례 페이지 — 세리프 번호 + 잉크 항목명 + 점선 리더 + 페이지. 디바이더는 거대 세리프 섹션 번호 + 헤드라인. 인용은 풀쿼트 32pt Source Serif 4 + 첫 인용부호 잉크 레드.
- 모든 다이어그램 SVG 정밀 렌더 — div 블록 금지.

## 하지 말 것
- 강조색을 면 채움·배경에 쓰지 말 것 — 잉크 레드는 차트 막대 1개·핵심 수치 1개·드롭캡·인용부호처럼 점(point)으로만.
- 무지개 차트·범례 박스·3D·격자선 과다 금지.
- 박스를 솔리드 색으로 채우지 말 것 — 구획은 가는 룰 라인으로. 카드 채움 최소.
- 둥근 모서리·드롭 섀도·그라디언트 금지.
- 헤드라인을 산세리프로 쓰지 말 것 — 헤드라인·거대 수치는 세리프, 캡션·본문은 산세리프(혼합이 정체성).
- 이모지 불릿·클립아트·스톡 아이콘 금지. 슬라이드를 글로 가득 채우기 금지.
- 모든 슬라이드 중앙 정렬·동일 레이아웃 반복 금지 — 잡지처럼 슬라이드마다 칼럼 수·룰 구획을 달리한다.

## 적용 예
- **표지.** 오프화이트 지면, 상단 11pt 대문자 키커, 그 아래 44pt 세리프 헤드라인 2줄, 섹션 룰 라인, 하단에 산세리프 발표 정보 + 세리프 이탤릭 날짜.
- **본문(스테이트먼트).** 상단 30pt 세리프 헤드라인 + 룰. 본문 첫 글자 드롭캡(3줄 높이), 2단 칼럼 본문, 칼럼 사이 헤어라인 룰.
- **프로세스 다이어그램 슬라이드.** 36pt 세리프 번호 01~04, 각 단계 세로 룰 라인 구획, 옆에 세리프 캡션. 화살표 없이 번호·룰로 흐름.
- **타임라인 다이어그램 슬라이드.** 수평 룰 베이스, 큰 세리프 연도 5개, 수직 틱 사건, 현재 연도만 잉크 레드.
- **매트릭스 다이어그램 슬라이드.** 표 형식 2×2 룰 격자, 데이터 잉크 레드 점 6개(크기=매출), 모서리 세리프 대문자 라벨, 좌측 해설 칼럼.
- **차트 슬라이드.** 잉크 단색 막대 7개, 3번 막대만 잉크 레드, 막대 위 13pt 값, x 베이스라인 헤어라인, 하단 세리프 이탤릭 출처 각주.
- **KPI 슬라이드.** 룰 라인 구획 4칸 — "독자 320만", "전년比 +14%" 등, 거대 54pt 세리프 수치 + 대문자 캡션, 칸마다 출처 각주.
