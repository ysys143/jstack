# 90s 멤피스 레트로 — ppt 디자인 팩

## 이 스타일의 정체성
1980~90년대 멤피스 그룹의 포스트모던 키치를 슬라이드로 옮긴다. 채도 100%에 가까운 원색 블록이 충돌하고, 지그재그·도트·테라조 패턴 조각과 비정형 기하 도형(반원·삼각형·물결)이 슬라이드 가장자리에 부유하듯 흩뿌려진다. 모든 요소가 비대칭으로 어긋나 있고 정렬을 의도적으로 거부한다 — 한눈에 "명랑한 무질서"로 식별된다.

## 색
- 배경: `#F4ECD8`(크림 오프화이트). 또는 슬라이드 1/3 면적에 `#1A1A1A` 컬러 블록.
- 텍스트: `#1A1A1A`(잉크 블랙). 컬러 블록 위에서는 `#F4ECD8`.
- 원색 팔레트 5개 — 멤피스 충돌색: `#FF3B7F`(핫핑크), `#00B5C9`(시안), `#FFC400`(옐로), `#7C4DFF`(바이올렛), `#FF5722`(오렌지). 한 슬라이드에 최소 3색을 동시 사용한다.
- 패턴: 검정 도트 그리드, 검정 지그재그 라인, 테라조 컬러 스플래터를 장식 조각으로만 사용.
- 그라디언트 절대 금지. 모든 색은 단색 플랫 채움.

## 타이포그래피
- 헤드라인: `Archivo Black` (대체: `Pretendard ExtraBold`, sans-serif). 표지 54pt, 본문 슬라이드 제목 40pt. 자간 -0.01em. 색은 원색 중 하나.
- 본문: `Poppins SemiBold` (대체: `Pretendard SemiBold`). 26pt, 행간 1.3. 슬라이드당 6줄 이하.
- 캡션/라벨: `Poppins` 16pt, 대문자, 자간 0.08em.
- 제목은 의도적으로 1~3도 기울여 배치한다. 본문은 수평 유지.

## 레이아웃 / 그리드
- 캔버스 16:9 (13.33×7.5in). 좌우 여백 0.7in, 상하 0.6in — 단 장식 도형은 여백·블리드를 침범해도 된다.
- 그리드는 참조용 6열. 콘텐츠 블록은 그리드에 의도적으로 어긋나게 배치(셀 경계에서 ±0.3in 오프셋).
- 매 슬라이드 기하 도형 3~5개를 모서리·여백에 부유 배치. 같은 배치를 두 슬라이드에서 반복하지 않는다.
- 제목은 좌상단 또는 우상단 — 슬라이드마다 번갈아.

## 형태 / 질감
- 도형: 정원·반원·삼각형·물결 띠·계단형 막대. 모서리 반경 0 또는 완전 원 — 중간 라운드 금지.
- 보더: 검정 3pt 솔리드 외곽선을 키 도형에 적용. 박스 채움색 + 검정 외곽선 조합.
- 그림자: 오프셋 하드 섀도만 — 블러 0, 검정 100% 불투명, 6pt 6pt 오프셋. 확산(soft) 그림자 금지.
- 이미지: 사용 시 검정 3pt 보더 + 도형 클리핑(원·삼각형 마스크). 사각 사진 그대로 금지.

## 전환 (PPT)
- 전환은 Push 또는 Wipe, 0.3s. Fade·Morph 금지 — 도형이 튀어드는 경쾌함 유지.
- 도형 등장은 Zoom/Bounce 애니메이션 허용.

## 하지 말 것
- 그라디언트·확산 그림자·둥근 카드(중간 라운드) 금지.
- 모든 요소를 그리드에 반듯하게 정렬하지 말 것 — 비대칭이 정체성이다.
- 무채색 회색 톤으로 색을 죽이지 말 것. 파스텔로 채도를 낮추지 말 것.
- 슬라이드마다 동일 레이아웃·동일 도형 배치 반복 금지.
- 이모지 불릿·스톡 아이콘·클립아트 금지. 장식은 기하 도형·패턴으로만.
- 슬라이드를 텍스트로 가득 채우지 말 것.
- **차트 금지사항(아마추어 회귀 차단):** 3D·원근·입체 막대 금지. 확산(soft·블러) 그림자 금지 — 하드 오프셋 섀도만. 격자선(grid line) 금지. 범례 박스 금지 — 직접 레이블링만. 잘린 y축(0에서 시작하지 않는 축) 금지 — 막대 비례 왜곡. div·표 셀로 대충 그린 막대 금지 — SVG 정밀 렌더. 무지개색을 의미 없이 칠하지 말 것(원색 충돌은 멤피스 정체성이지만, 비교 차트에서 강조 막대는 1개로 명확히).

## 차트·데이터 시각화
멤피스 차트 = 원색 평면 채움 + 두꺼운 검정 보더 + 거친(의도된) 정렬. 컨설팅 차트의 무채색 절제와 정반대지만, 데이터 잉크 원칙은 동일하게 지킨다.
- **렌더링:** 모든 차트는 SVG로 정밀하게 그린다. 막대 폭 : 간격 = 3 : 2 고정. 모든 막대 하단은 동일 기준선에 정확히 정렬, 기준선은 값 0. 잘린 y축 금지.
- **축·격자:** 격자선 완전 제거. y축선 제거. x축(기준선)만 검정 2.5pt 솔리드 라인 1개. 눈금 라벨 없음 — 값은 막대에 직접 표기.
- **데이터 색:** `tokens.json`의 `color.chart` 5색(`#FF3B7F`·`#00B5C9`·`#FFC400`·`#7C4DFF`·`#FF5722`)을 막대에 순환 평면 채움. 각 막대에 검정 3pt 솔리드 외곽선 + 6pt 6pt 하드 오프셋 섀도(블러 0, `#1A1A1A` 100%). 비교에서 가장 중요한 막대 1개는 핫핑크 `#FF3B7F`로 고정해 시선을 잡는다.
- **값 레이블:** 막대 위 직접 표기. `Poppins SemiBold` 20pt `#1A1A1A`, 단위·자릿수 일관. 막대보다 살짝 기울임(1~2도) 허용 — 멤피스 거친 정렬.
- **직접 레이블링:** 범례 박스 금지. 계열·항목 이름은 막대 아래(x축 라벨) 또는 막대 끝에 `Poppins` 16pt 대문자로 직접 붙인다.
- **차트 타입:** 비교=세로 막대(원색 채움), 비중=도넛(조각 3개 이하, 각 조각 원색 + 검정 3pt 보더, 중앙에 핵심 수치 `Archivo Black` 40pt). 추세=계단형 막대 또는 굵은 검정 4pt 꺾은선 + 원색 도트 꼭짓점. 파이 5조각+·다중 도넛 금지.
- **장식:** 차트 주변 여백에 검정 지그재그 띠·도트 그리드 패턴 조각 1~2개를 부유 배치(차트 데이터 영역은 침범하지 않음).

## 다이어그램·컴포넌트
멤피스 다이어그램 키트 = 원색 평면 채움 도형 + 검정 3pt 외곽선 + 6pt 6pt 하드 오프셋 섀도(블러 0, `#1A1A1A` 100%). 노드는 의도적으로 1~3도 어긋나게, 커넥터는 검정 굵은 셰브론·꺾은 화살표. 모든 다이어그램이 이 한 언어를 공유한다 — 차트와 동일한 보더·섀도·원색 운용. 전부 SVG 정밀 렌더, div 블록 금지.
- **공통 다이어그램 언어:** 노드 도형은 모서리 반경 0 사각 또는 완전 원·반원만(중간 라운드 금지). 외곽선 검정 3pt 솔리드. 하드 오프셋 섀도 6pt 6pt. 단계 번호 배지는 지름 0.5in 정원, 원색 평면 채움 + 검정 3pt 외곽선, 안에 `Archivo Black` 24pt 흰/검정 숫자. 활성·강조 노드 1개만 핫핑크 `#FF3B7F`, 나머지는 `color.chart` 나머지 4색 순환.
- **프로세스 플로우:** 가로 4~5단계. 각 노드는 사각 1.7in×0.9in, 원색 평면 채움 + 검정 3pt 외곽선 + 하드 섀도. 노드 좌상단에 0.5in 번호 배지. 커넥터는 검정 4pt 셰브론(▶), 노드 간격 0.4in. 노드 라벨 `Poppins SemiBold` 18pt. 노드 베이스라인을 ±0.15in 지그재그로 어긋나게 배치.
- **타임라인:** 수평. 굵은 검정 4pt 솔리드 축선 1개. 마일스톤 마커는 지름 0.4in 정원(원색 평면 + 검정 3pt 외곽선), 축 위아래 교차 배치. 날짜 라벨 `Poppins` 16pt 대문자. 현재 시점은 핫핑크 `#FF3B7F` 정원 + 위쪽에 옐로 삼각형 포인터 1개.
- **비교 레이아웃:** 2~3열. 각 열은 원색 평면 채움 패널(검정 3pt 외곽선 + 하드 섀도), 열마다 다른 원색. 열 상단에 0.6in 헤더 띠(검정 채움 + 크림 텍스트 대문자). 열 사이 구분선 없음 — 0.4in 간격 + 색 충돌로 분리. 가운데에 검정 "VS" 원형 배지 1개.
- **매트릭스 2×2:** 두 축은 검정 4pt 솔리드 라인. 사분면은 4개 원색으로 각각 평면 채움(불투명도 100%, 검정 3pt 외곽선). 축 라벨 `Poppins` 16pt 대문자. 데이터 포인트는 지름 0.45in 정원(검정 3pt 외곽선 + 하드 섀도), 라벨은 점 옆 16pt.
- **계층/퍼널:** 3~4단 계단형 막대(stair-bar) 또는 폭이 줄어드는 사각 스택. 각 단은 다른 원색 평면 채움 + 검정 3pt 외곽선 + 하드 섀도. 단 사이 0.15in 간격. 레벨 라벨은 단 안에 `Archivo Black` 22pt. 정렬은 좌측 기준 또는 의도적 비대칭 — 중앙 정렬 금지.
- **KPI·스탯 카드:** 사각 카드 2.6in×2.0in, 원색 평면 채움 + 검정 3pt 외곽선 + 6pt 하드 섀도. 거대 수치는 `Archivo Black` 64pt(2도 기울임), 라벨은 하단 `Poppins` 16pt 대문자, 증감은 검정 삼각형(▲▼) + 수치 20pt. 카드는 베이스라인을 어긋나게 나열.

## 적용 예
- 표지: 크림 배경, 좌상단에 핫핑크 54pt 제목(2도 기울임), 우하단에 시안 반원 + 옐로 삼각형 + 검정 지그재그 띠. 하단 라벨 대문자 16pt.
- 본문: 좌측 옐로 컬러 블록(슬라이드 1/3, 검정 외곽선), 그 위 검정 제목. 우측에 본문 4줄 + 바이올렛 정원 1개 부유.
- 차트: SVG 세로 막대 차트, 막대 폭:간격 = 3:2. 막대는 `color.chart` 5색 순환 평면 채움 + 검정 3pt 외곽선 + 6pt 하드 섀도(블러 0). 핵심 막대 1개는 `#FF3B7F` 고정. 격자선·y축·범례 전부 제거, x축만 검정 2.5pt. 값은 막대 위 20pt `Poppins SemiBold`로 직접 표기, 항목명은 막대 아래 16pt 대문자.
- 프로세스 슬라이드: 가로 4단계 플로우. 각 노드 사각 1.7in×0.9in, 원색 평면 채움 + 검정 3pt 외곽선 + 하드 섀도, 좌상단 0.5in 번호 배지. 커넥터는 검정 4pt 셰브론. 활성 단계만 핫핑크. 노드 베이스라인 지그재그 어긋남.
- 매트릭스 슬라이드: 2×2 사분면, 두 축 검정 4pt 라인. 4개 원색 평면 채움 사분면. 데이터 포인트는 0.45in 정원 + 검정 외곽선 + 하드 섀도. 모서리에 도트 그리드 패턴 조각 1개 부유.
