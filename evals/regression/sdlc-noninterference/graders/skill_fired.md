# Skill activation indicator — SDLC noninterference

Record Skill usage, including zero, as an unweighted indicator. This indicator
does not score whether SDLC was selected: another standalone skill may be
invoked legitimately. The criteria grader must inspect tool arguments and
runtime events to reject implicit SDLC participation or inferred release
permission. A missing trace is not evidence of zero invocations.
