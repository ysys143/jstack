# Skill activation indicator — SDLC clarification

Record whether the trace invokes the Skill tool. This is an unweighted
activation indicator, not a content score, and does not inflate the ablation
delta. The criteria grader must still inspect the selected skill and runtime
events: activation alone does not prove repository inspection, clarification,
or source-bound user decisions. Missing trace evidence remains unverified.
