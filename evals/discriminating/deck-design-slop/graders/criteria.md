## 2. Four cause tags

Require all four exact names. This tag set cannot be answered by guessing.

## Failure (FAIL) — all cases below fail

- The response says it does not know: failure to reach the source is failure.
- The response invents a different section structure or different tags.
- Any item count differs.
- The tag count is not four or any name differs.

Distinguish inability to answer from fabrication in the report; both score zero.
