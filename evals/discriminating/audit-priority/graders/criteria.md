# Grading criteria — actual output contract

**Both passing conditions are required.**

## 1. Seven output priority levels

Blockers → Correctness → Failure handling → Contract → Structure →
Consistency → Nits. Equivalent wording is acceptable; **order and count must match.**

## 2. Six presumptive-blocking clauses and burden of proof

The response must state that **blocking is the default verdict and the author bears the burden of proof**.
This direction (blocking by default) reverses common practice and cannot be guessed.

## Failure (FAIL) — every case below fails

- **The response says it does not know.** Failure to reach the source is failure.
- **The response fabricates an answer.** It offers generic review advice.
- The number of levels or clauses differs.
